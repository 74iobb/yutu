# 板面设计审计（2026-11-25）

> 目标：让四个步骤、沙盘与独立页使用同一套「页面级 → 板块级 → 局部流程」层级，
> 不靠新增装饰，而靠编号、留白与折叠把信息讲清楚。

## 0. 统一规则

| 层级 | 视觉 | 用途 | 例子 |
|---|---|---|---|
| 页面级 | `.y-eyebrow` + `STEP 0N · 名称` | 你在第几步、这一步是什么 | `STEP 03 · 方向与推演` |
| 页面标题 | `.y-lead h2` | 一句话说清这一步要做什么 | 「你的处境、约束与归属」 |
| 板块级 | `.y-zone-n` + `0N / 名称` | 页内分区，只在本页内递增 | `01 / 主图`、`02 / 代价` |
| 局部流程 | 无编号或 `① ② ③` | 同一板块内的操作顺序 | 方向清单 → 二阶深挖 → 代价 |

**为什么改**：此前步骤标签、板块编号、局部流程都用 `01 / 02 / 03`，
例如第 3 步里同时出现「03 / 方向清单」「01 / 基本事实」「01 方向清单」，
读者无法判断哪个数字是步骤、哪个是分区。现在步骤一律带 `STEP` 前缀，
页内分区保留 `0N /`，两者不再混用。

其它固定规则：

- 每页最多一条 `.y-insight`（本步结论）；没有结论就不要硬造。
- 主内容 + 侧栏：主列放判断与操作，侧栏放证据、约束与次要入口；移动端侧栏后置。
- 次要输入 / 长证据默认折叠；首屏只留「结论 + 一个主动作 + 主内容开头」。
- 编号不跨页复用；`0N /` 只在当前页面内递增。
- 所有数据展示必须能追溯到 `src/data/provenance.ts`；缺口见「数据来源与口径 → 按图表看依据」。

## 1. 逐板面

### Shell（全局外壳）
- **结构**：品牌 + 标题/副标题 → 数据状态 / 闭环 / 动效 / 更多 → 两区导航（处境 / 成长）→ 四步条 → 阅读进度。
- **做得好**：吸顶、滚动进度、动效开关、数据状态入口集中；两区导航与四步条分工清楚。
- **问题**：导航有三层（两区 / 四步 / 页内视图），移动端 chip 行偏密；步骤条与页内 `STEP` 标签需要互相呼应。
- **本轮**：步骤标签统一 `STEP 0N`，与顶部步骤条一致。
- **后续**：移动端可考虑把四步条收成横向滚动；不新增第五个 chip。

### 第 1 步 · 填写信息
- **结构**：页头 → 成长变化条 → 快速定位 → 主表单（基本事实 / 结构化测量 / 校准）→ 右侧判定卡 → 底部唯一主按钮。
- **做得好**：表单与判定分离；右卡 sticky；快速定位解决长表单跳转；底部只有一个主 CTA。
- **问题**：移动端判定卡在主表单之后，首屏看不到阶段结论；卡片内 `01 / 基本事实` 与页头 `01 / 处境` 曾共用编号。
- **本轮**：页头改为 `STEP 01 · 处境`，卡片编号保留为板块级。
- **后续**：移动端可在快速定位条旁加一个「当前阶段」小胶囊，避免必须滚到底。

### 第 2 步 · 了解环境
- **结构**：宽页头 + 城市/阶段/邻城事实 → 本步结论 → 地图主卡 + 右侧两页签（城市 / 讨论）。
- **做得好**：地图是唯一主角；事实条让首屏先给结论；侧栏有自动轮播与暂停。
- **问题**：地图卡头部同时放模式切换、聚焦、图例、资料开关、说明折叠，控制密度高；侧栏没有板块级标题，和地图的 `01 / 地图` 不成对。
- **后续（P2）**：侧栏加 `02 / 城市与讨论` 的板块头；把「资料点与飞线」开关移到图例旁；考虑默认关闭自动轮播，手动优先。

### 第 3 步 · 方向与推演（Step34 三视图）
- **结构**：视图切换（方向清单 / 作战图 / 归属摘要）→ 当前视图。
  - 清单：页头 → 三步流程 → 本步结论 → 你的想法 → 检索依据 → 方向列表 + 侧栏。
  - 作战图：页头 → 本步结论 → `01 / 主图` → `02 / 代价` → 折叠 `03 / 关系`。
  - 摘要：页头 → 四指标 → 本步结论 → 主列 SET + 侧栏约束 → 导出。
- **做得好**：三视图共享候选与选定方向；作战图的分区编号最完整；摘要像仪表盘。
- **问题**：清单视图首屏堆了 4 个块（流程 / 结论 / 想法 / 检索依据）才到方向列表；三步流程与顶部视图切换语义接近，容易混；侧栏的「同类处境者记述」很长，和主列表争夺注意力。
- **本轮**：「你的想法」改为折叠块（已填写时摘要显示「已填写，参与检索」），首屏少约 90px；步骤编号改为 `STEP 03`。
- **后续（P1）**：把三步流程并入方向列表卡头；检索依据在桌面端移入侧栏，移动端保留折叠；考虑给方向列表加「只看当前可做」的 sticky 过滤条。

### 第 3 步 · 作战图（Step4 组件）
- **结构**：页头 → 本步结论 → `01 / 主图`（地图 + 控制）→ `02 / 代价`（资源 / 代价 / 候选）→ 折叠 `03 / 关系`。
- **做得好**：全站最完整的「板块级」结构；主图优先；关系证据折叠，不打断阅读。
- **问题**：主图卡内部的控制、图例、HUD、资料开关仍然密集；`02` 里资源与代价并排，窄屏会变很长。
- **后续（P2）**：把地图控制收成一行图标 + 更多；`02` 在移动端改为按「资源 → 代价 → 候选」分步。

### 第 3 步 · 归属与摘要（StepSummary）
- **结构**：页头 → 四指标 → 本步结论 → 警告 → 主列 S / T / 逐维贡献 + 侧栏 C / R / 模型边界 / 导出。
- **做得好**：指标先行，主侧分工清楚；导出在侧栏底部。
- **问题**：警告是裸 `y-warn` 段，和卡片层级不统一；主列三段较长。
- **后续（P2）**：把 warnings 收进一张「模型边界与提示」卡；侧栏「模型边界」与 warnings 合并，避免两处说同一件事。

### 第 4 步 · 成长闭环（Step6）
- **结构**：页头 → `01 / 闭环顺序`（当前步骤卡 + 六站点）→ `02 / 闭环全貌`（螺旋图 + 侧栏）→ `03 / 本轮工作区`（工作台 / 驿站 / 回看）→ `04 / 档案与同伴`（档案墙 / 同伴经验域）。
- **做得好**：四区编号完整；子页签与聚焦模式；新螺旋图让轮次可累积。
- **问题**：同一状态在四处重复（当前步骤卡、六站点、螺旋图、图侧文案）；页面很长；页头的「先在沙盘里试走一轮」是独立按钮，和闭环主体关系弱。
- **后续（P1）**：把 `01` 的六站点收成「当前步骤 + 展开完整顺序」；`02` 的图侧文案只保留一个主动作 + 关键指标；沙盘入口改为 `01` 里的次级入口，避免页头长按钮。

### 沙盘（#/sandbox）
- **结构**：独立页头 → 主张 → 未完成第 1 步提示 → 当前处境四卡 → 棋盘 + 动作面板 → 结果对照 → 采纳。
- **做得好**：独立视觉身份；资源约束与「无随机」写清楚；自定义路径的检索原文可核对。
- **问题**：页面长；右侧面板在自定义表单展开时会超过视口（已加内部滚动）；结果对照的三栏在窄屏变三行。
- **后续（P2）**：结果区可加「只看结论」折叠；窄屏把三栏收成一张对比表。

### 电气实训（#/electrical）
- 独立页，不参与四步；保留现有版式。仅需保证入口从「更多」可达。

## 2. 本轮已落地

1. 步骤级标签统一为 `STEP 0N · 名称`（Step1/2/3/4/34/Summary/6、方向星图、经验星云），与顶部步骤条对齐；页内 `0N /` 仍表示板块。
2. 第 3 步「你的想法」改为折叠块，已填写时摘要显示状态，首屏更短。
3. 数据依据审计页签（`按图表看依据`）为所有板面的数字提供统一口径入口。
4. 第 4 步闭环去重：六站点默认收进「完整六步」折叠；唯一主 CTA 上移到「当前步骤」卡并统一为 `primary`；螺旋图侧的主操作降为次级快捷；沙盘入口从页头长按钮降为当前步骤卡内的次级链接。
5. 第 2 步侧栏新增 `02 / 城市与讨论` 板块头，与地图卡的 `01 / 地图` 成对。
6. 第 3 步局部流程改为 `① 方向清单 / ② 二阶深挖 / ③ 代价与清单`，二阶抽屉同步；与 `STEP 0N`、`0N /` 形成三级区分。

## 3. 优先级建议

- **P1**：Step6 去重（当前步骤卡 / 六站点 / 图侧文案）；Step3 清单首屏再收一层。
- **P2**：Step2 侧栏板块头与自动轮播默认策略；StepSummary 警告与模型边界合并；Step4 控制条收口。
- **不做**：为了「高级」新增孤立字号、颜色或第三层导航；在深色底上恢复浅色卡片。
