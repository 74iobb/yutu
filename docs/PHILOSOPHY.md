# 域途 · 产品圣经

> 一句话：**不教人怎么过一生，只做真实环境的显影仪与决策沙盘。**

这份文档是产品与工程的共同约束。任何界面文案、模型输出、数据接入，先过这一页。

---

## 1. 反叛：拒绝「爹味规划」

- 不给建议，不排序「哪条路更好」，不输出「你应该去哪里」。
- 系统不提供解法，只提供**呈堂证供**：真实原文、已知条件、资源消耗、代价与风险。
- 定义权、评判权、选择权 100% 归用户。

**工程禁令**

- 界面不出现「推荐 / 建议 / 最好 / 应该选 / 优先选」。
- 模型与规则只允许输出客观事实与条件判定；不给概率、不做成败预测。
- 文案只陈述「是什么 / 要付什么 / 现在够不够」，不替用户下结论。

---

## 2. 机制：环境侦察 → 自主决策 → 深度推演 → 复盘拷问

| 环节 | 用户动作 | 系统只做什么 | 当前实现 |
|------|----------|--------------|----------|
| 认清自己 | 填城市、年龄、身份、负担 | 生成七维处境与当前归属，不贴标签 | 第 1 步 + 七维模型 |
| 看清世界 | 选城市、看方向 | 展示知乎真实原文、城市近似属性、资源与代价 | 第 2/3 步 + 知乎快照 |
| 自主决策 | 选方向 / 加入候选 / 写下自己的路 | 呈现客观选项池，不逼迫 | 第 3 步方向清单 + 沙盘自定义路径 |
| 深度推演 | 加一步，再加一步 | 顺着决定列已知条件、投入与检索原文 | `#/sandbox` 沙盘 |
| 复盘拷问 | 实践后回来 | 对比起点与现在，只问「还是你要走的路吗」 | 第 4 步 + 灵魂拷问 |

### 沙盘的两条硬规则

1. **预设动作是规则，不是推荐。** 每个动作的成本与七维效果公开写在 `src/lib/sandbox.ts`。
2. **自定义的路由用户定义。** 系统只记录「你决定做这一步」、你选择的投入强度、以及检索到的真实原文；**不推断这一步的七维变化**，也不判断值不值得。

用户自定义一步后，系统只问下一句：**「这是你的决定。下一步还要加什么？」**

---

## 3. 真实：不做算命先生

- **RAG 而非幻觉**：检索范围是仓库内 256 条知乎快照 + 精编案例；界面展示原文标题与可点击链接。
- **检索不到就说检索不到**：不得用通用内容伪装成「按你的方向检索」。
- **来源分级**：REAL / SELF / CURATED / APPROX / HEURISTIC 五类，界面必须挂 `DataSourceBadge`，统一登记在 `src/data/provenance.ts`。
- **没有数据就不画**：宁可空态，也不编造「同路人去向」「成功率」「百分比精度」。
- **固定规则、无随机**：沙盘不含随机数；改规则必须同步文档与口径。

---

## 4. 当前实现与已知缺口

已实现：

- 七维处境、归属相似度与稳定度（HEURISTIC，未校准，界面明示）。
- 知乎内容快照 + 原文链接 + 数据来源面板。
- 方向清单、二阶检索、作战图、归属摘要。
- 成长闭环：体验任务 → 归档 → 漂移 → 复盘 → 灵魂拷问。
- 沙盘：6 格 × 一季度；预设动作 + **用户自定义的路**；资源约束；与「维持现状」对照；可采纳为体验任务。
- 同伴经验域：复盘、有效标记、讨论、素材、搜索；全部基于自填/公开数据。

明确缺口（不要在没数据时假装有）：

- 当前是**七维**处境，不是四维雷达；四维是早期表述。
- **同路人「去了哪里」**：现有表只记录作者处境城市与下一步选择，没有「去向城市」。因此地图飞线目前仍表示岗位密度 / 资料归属，不能声称是「同路人的真实下场」。如要落地，需要先新增去向城市字段与明确的用户授权，再画线。
- 大模型 RAG 直答未接入；当前是「真实语料检索 + 固定规则」，不是生成式推演。

---

## 5. 视觉与情绪

- 暗色玻璃、星空/叶面背景、流光飞线与弹珠棋子，服务于「在沙盘上看见自己的处境」，不是装饰堆叠。
- 所有动效遵循 `prefers-reduced-motion` 与顶栏「动效 关」。
- 最后一步的情绪来自**真实对比**（起点 → 现在、决定 → 代价），不来自抒情文案。
- 现场演示必须有兜底：检索失败 / 平台接口不可用时，明确提示并保留本机数据，不白屏、不编造。

---

## 6. 共建共享（V2.0 愿景）

- 用户完成复盘后，可脱敏共享「路径标签」。
- 后来者看到的是**真实前人的复盘**，不是系统替他们总结的「成功学」。
- 不排名、不展示薪资与结果对比；只让每一种真实的活法被看见。
