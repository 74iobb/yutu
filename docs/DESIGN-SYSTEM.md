# 域途 · 设计系统（V6 试点）

> 目标：把“好看的页面”升级成“可扩展的产品系统”。本文件先覆盖已经落地的令牌、卡片层级、图表外壳与成长河；其余页面按同一套规则逐步迁移。

规则：

- 内容面（卡片、表单）只用 `paper / surface`；品牌色只做强调。
- 页面底色允许彩玻璃光场，但不直接承载正文：正文始终放在 `paper / surface` 卡片或半透明纸面上。
- 数据色最多 6 个，并配文字、形状或标签，不仅靠颜色区分。
- 深色视图统一 `night + #E9F2ED`。
- 正文对比度按 WCAG AA 检查。

### 1.1 星空透入（V8）

- 最底层是用户提供的叶面水珠照片：以 72s 缓慢平移、缩放、旋转，叠加淡蓝/淡紫呼吸光晕。背景照片仅限本项目使用，对外发布前需确认授权。
- `#yutu2` 是半透明深色玻璃（当前约 `rgba(5,10,22,.28 → .18)`），星云直接透过应用内部；**不要在 `#yutu2` 上加 `backdrop-filter`**（会成为 fixed 后代的包含块，破坏数据面板 / toast / 聚焦层定位）。卡片是磨砂玻璃（约 `rgba(6,12,24,.50 → .42)` + `backdrop-filter: blur(12px)`），星云颜色会透出，但被磨砂层柔化以保证文字可读；blur 只加在主要容器上，嵌套小面不重复叠加。
- 正文、标题、表单、标签统一改为浅色（`ink = #e9efff`），次级文字用 `ink-2 / muted`；主按钮与当前步骤保留彩玻璃作为唯一高饱和强调。
- 二级按钮、输入框、下拉、textarea、chips、地图控件、同步/数据面板都使用深色玻璃表面；地图瓦片与图表绘图区可以保留亮色内嵌面。
- 照片类空隙（`GapPhoto`）在暗色主题下统一压暗并叠底部暗层；`sunrise` 变体额外压暗太阳区域，避免在深色界面里形成过曝亮块。成长变化条、提示气泡、子标签选中态也必须是深色玻璃，不得保留暖白/亮绿底。
- 头部状态 chip（尤其 `.y-sync-wrap .y-chip`）必须显式覆盖为深色玻璃；旧规则优先级高于 `.y-chip-c`，不能只改 `.y-chip`。在线状态只用绿色小圆点表达，不加呼吸光晕。
- 闭环的选中子页签（体验工作台 / 停靠驿站 / 胜利档案墙 / 同伴经验域）与主按钮共用彩玻璃底图；不要再使用绿色或蓝色纯色渐变作为选中态。
- 所有星空动效在 `prefers-reduced-motion` / 「动效 关」下退化为静态星空；暗色玻璃本身不依赖动画。

## 2. 空间与形状

- 间距：4 / 8 / 12 / 16 / 24 / 32 / 48
- 圆角：`--radius-1:8` / `--radius-2:12` / `--radius-3:18` / `--radius-4:24`
- 阴影：`--shadow-1` 数据卡 / `--shadow-2` 主卡 / `--shadow-3` 沉浸面板
- 排版：
  - 页面标题 28–38 / 1.2 / 700
  - 区块标题 18–20 / 1.35 / 680
  - 卡片标题 15–16 / 1.45 / 660
  - 正文 13 / 1.75
  - 注释 11 / 1.6
  - 数字使用 `font-variant-numeric: tabular-nums`

## 3. 卡片层级

| 类 | 用途 | 视觉 |
|---|---|---|
| `.y-card` | 默认内容卡 | 白底、细描边、轻阴影 |
| `.y-card--data` | 数据/对比卡 | 更浅的米色渐变、`shadow-1` |
| `.y-card--evidence` | 时间轴/证据卡 | `surface-2`、无阴影、低对比 |
| `.y-chart-frame` | 主图表卡 | 暖白渐变、品牌绿描边、`shadow-2` |
| 沉浸卡 | 星图/星云/聚焦 | `night` 或深色玻璃 |

新页面先决定“这张卡是主卡、数据卡还是证据卡”，再选类，不要所有卡片同一层级。

## 4. 图表外壳 `ChartFrame`

统一负责：

- eyebrow / 标题 / 副标题
- 右上操作（切换图表、筛选）
- 图例（dot / line）
- 空态、加载骨架
- 脚注（口径、样本不足、边界）

页面只提供图表本身，不再各自写卡片标题、空态和说明。

## 5. 成长河 `GrowthRiver`

- 七维归一化后做 streamgraph，中心堆叠
- Catmull-Rom 平滑，手写路径，不引入 d3-shape
- 每个维度有自己的数据色和渐变
- 悬停 / 键盘聚焦横切，显示该次归档的原始数值
- 末端「现在」虚线；支持 reduced-motion 静态
- 入口：第 5 步 → 档案墙 → 成长图表，可在「成长河 / 单维曲线」之间切换

## 6. 后续扩展规则

1. 新图表先套 `ChartFrame`，再决定用 SVG / Canvas；
2. 超过约 200 个 SVG 元素切 Canvas，超过 3000 再考虑 WebGL；
3. 常规统计图优先 `d3-scale + d3-shape`；复杂仪表盘再懒加载 ECharts；
4. 星图、星云、闭环轮盘保持自绘，不套通用图表库；
5. 所有新组件必须支持 `prefers-reduced-motion` 与「动效 关」；
6. 新色值先加语义 token，不在组件里写死十六进制。

## 7. 三态光色与玻璃语汇（V11.16）

参考母题：**水下 → 退潮 → 彩玻璃**。三种状态对应同一世界的三种光学层，不是三套皮肤。

### 7.1 每步光色令牌

| 步骤 | `data-step` | `--step-accent` | 语义 |
|---|---|---|---|
| 填写信息 | `1` | `#4fc9e6` 水青 | 沉浸、显影 |
| 了解环境 | `2` | `#4fc9e6` 水青 | 退潮后的证据 |
| 方向与推演 | `3` | `#d8bf8c` 沙金 | 分岔、观察 |
| 成长闭环 | `4` | `#e2aa2e` 玻璃琥珀 | 拼合、透光 |
| 沙盘 | `sandbox` | `#d8bf8c` 沙金 | 实体推演 |

规则：

- 每屏只允许一个主 accent；颜色表达状态，不做装饰。
- 主按钮与当前步骤继续用彩玻璃底图，是全站唯一允许高饱和的地方。
- 不直接把带水印参考图放进项目；需要干净素材时另出无字版本。

### 7.2 新增语汇

| 语汇 | 类名 | 用法 |
|---|---|---|
| 场记线 | `.y-lead > .y-eyebrow::before` | 页面级 eyebrow 前 22px 光色短线 |
| 铅条分隔 | `.y-zone > .y-zone-head::before` | 1px 深色线 + 30px 当前光色 |
| 玻璃碎片 | `.y-dir::before` + `--dir-hue` | 方向卡顶部 48px 彩色边；选中时铺满整条 |
| 侧栏玻璃轨 | `.y-glass-rail` | Step3 方向清单 / 归属摘要侧栏边缘的 2px 五色竖线；窄屏变顶部横线 |
| 光学带 | `.y-optical-band` + `OpticalBand` | Step1 水下焦散 / Step2 退潮海岸 / Step3 彩玻璃 / Step4 年轮；236px（窄屏 150px），mask 渐隐，不承载数据 |
| 门槛 | `.y-portal` + `PortalSlab` | 沙盘页右上角的琥珀斜板；取自真实大厅装置，只用形状与光，不引用照片；≤1040px 隐藏 |

### 7.3 禁止

- 不要把所有玻璃颜色同时铺满页面；一块屏最多 2 个彩色块。
- 不要用颜色单独表达可行性、状态或数据结论；必须配文字。
- 不要在正文卡上使用强烈彩色背景或大面积发光。

## 8. 数据来源与口径

- 五类：`REAL / SELF / CURATED / APPROX / HEURISTIC`，统一登记在 `src/data/provenance.ts`
- 主要数字/结论旁只放小标签（`DataSourceBadge`），完整口径集中在头部「数据来源与口径」面板
- 规则：近似值不用于对外陈述；启发式模型明示未校准；自填数据标明来源；不再保留虚构示例
- 新增数据时必须先登记 provenance，再接入界面；不允许在组件里写死未登记的口径
