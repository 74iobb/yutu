# 域途 · 动效规范（V5.13）

> 目标：动效服务功能，而不是炫技。所有动效都必须能回答三个问题：
> 这条动效**解释了什么**、**在什么触发条件下出现**、**关闭后是否仍可完成任务**。

## 1. 原则

| 原则 | 在本项目中的落地 |
|------|-----------------|
| 功能性 | 按钮按下有涟漪；表单缺失时聚焦 + 抖动 + 行内提示；切步有方向明确的转场；聚焦/星图有明确的退出口 |
| 自然适度 | 常规交互 160–420ms；翻书切页 760ms；不使用弹跳过度或连续震动；环境动效放慢到 5–52s |
| 一致性 | 统一 `--motion-*` 时长与 `--ease-out / --ease-spring` 曲线；同类触发使用同一套反馈 |
| 共情聚焦 | 递进显现引导阅读顺序；数字滚动与折线绘制帮助理解状态变化；归档完成用漂移条表达“移动了一小步” |
| 可关闭 | 系统 `prefers-reduced-motion` + 顶栏「动效 开/关」双重降级 |

## 2. 时长与曲线

| Token | 值 | 用途 |
|-------|----|------|
| `--motion-fast` | 160ms | hover、颜色、焦点环、小元素 |
| `--motion-base` | 240ms | 按钮、卡片、子标签、折叠 |
| `--motion-slow` | 320ms | 卡片悬浮、面板小转场 |
| `--motion-enter` | 420ms | 步骤切换、聚焦面板、星图、列表入场 |
| `--motion-ambient` | 18s | 标题流光、环境背景等常驻动效 |
| `--ease-out` | `cubic-bezier(.22, 1, .36, 1)` | 绝大多数进入与 hover |
| `--ease-in-out` | `cubic-bezier(.65, 0, .35, 1)` | 需要对称往复的呼吸类动效 |
| `--ease-spring` | `cubic-bezier(.16, 1, .3, 1)` | 有轻微“落定感”的进入、倾斜、磁吸 |

**硬规则**：常规交互动效（按钮、面板、弹层）应在 **500ms 内**结束；翻书切页属于叙事型转场，允许 **700–800ms**。纯装饰的常驻动效不受此限制，但必须低对比、低频率。

## 4. 技术约束

- **优先 `transform` / `opacity`**：位置、缩放、淡入淡出均使用这两类属性；避免动画 `height`、`top/left`。
- 允许少量小面积 `background-position`（标题、步骤条、编号胶囊）；大面积极光使用独立的 `transform` 图层。
- 所有指针/滚动监听使用 `passive` + `requestAnimationFrame`，并只写 CSS 变量，不触发 React 重渲染。
- 地图容器在聚焦/尺寸变化时通过 `ResizeObserver → invalidateSize` 重新计算，不依赖动画结束事件。
- 动效不得阻塞点击：所有装饰层统一 `pointer-events: none`。

## 5. 降级

1. **系统偏好**：`@media (prefers-reduced-motion: reduce)` 关闭全部新增动画、倾斜、磁吸与星图循环；内容直接呈现。
2. **手动开关**：顶栏「动效 开/关」写入 `localStorage: yutu.motionOff`；开启时给 `<html>` 加 `y-motion-off`，关闭全部 animation / transition，并隐藏装饰层。
3. **触屏 / 窄屏**：隐藏环境柔光、网格、光点、卡片聚光、切步扫光；地图与星图改为单列。
4. **无 JavaScript**：`index.html` 的 `noscript` 保证内容可见；关键操作不依赖动画完成事件。
