# 域途 · 展位方案（Threshold / 门槛）

> 参考：用户提供的大厅实拍——粉米色大理石地面、深色大理石柱、一块斜立的琥珀色装置、后方走廊。
> 结论：**不把照片放进 UI，而是把它变成展位的空间语言。**

## 1. 一句话

**一块斜立的琥珀色板 = 一道“决定之门”。**  
观众从走廊走来，先看到门，再看到沙盘；屏幕里的推演，最终要回到真实大厅里走。

## 2. 空间

- 建议 2m × 2m，单面开口，背靠实墙或柱子。
- **左侧**：低矮沙盘台（1.2m × 0.6m × 0.75m）。
- **右侧**：琥珀色斜板（1.8m 高 × 0.9m 宽），斜板正面嵌屏。
- 中间留 0.8m 站人；地上用一条 5cm 暖色胶带标出“门槛线”。
- 不要用海报墙；只留一块 A2 竖版图（水下 / 浅滩 / 彩玻璃三联），放在侧面。

## 3. 斜板（核心装置）

| 项 | 规格 |
|---|---|
| 尺寸 | 1.8m 高 × 0.9m 宽 × 0.12m 厚 |
| 倾斜 | 6–8°，像参考图里的斜立 |
| 材质 | 18mm 多层板，外贴哑光膜；边缘 20mm 深色封边 |
| 颜色 | 琥珀 `#F1A569`；背面与侧面压到 `#8A4A24` |
| 屏幕 | 27" 竖屏或 24" 横屏，嵌在正面 1.05–1.45m 高度，四周留 20mm 黑边 |
| 灯 | 顶部一盏 3000K 窄光束打在板面上，不直射屏幕 |
| 细节 | 板面留一条 1mm 蚀刻竖缝，对应参考图里的装置缝 |

屏幕内容：`/#/sandbox` 的「聚焦」态；预置一个演示档案；不要放说明书长文。

## 4. 沙盘台

- 台面 1.2m × 0.6m，深青灰哑光，蚀刻 6 格（对应 6 个季度）。
- 6 枚黄铜标记 + 1 颗玻璃弹珠；标记放在台前的小凹槽里。
- 台面左侧刻一行小字：**「这是你的决定。下一步还要加什么？」**
- 不做“正确路线”提示；不插旗、不打分。

## 5. 观众动线（3 分钟）

1. **门槛线**：观众站到胶带前，先看到斜板上的问题——**「你打算怎么走？」**
2. **沙盘**：从凹槽取一枚黄铜标记，放在第一格；屏幕同步出现一步。
3. **再加一步**：工作人员只问一句「下一步还要加什么？」不替观众选。
4. **看结果**：屏幕显示「这条路线 / 维持现状」的对照与资源余量。
5. **出口**：递一张小卡片，正面只有二维码与一句「推演完，回去走一步」。

## 6. 文案纪律

- 不说「推荐 / 建议 / 应该 / 最好」。
- 不承诺成功率、不预测结果。
- 只陈述：「这一步消耗什么」「走到第 N 格会落在哪」「维持现状会怎样」。
- 工作人员不解释“正确答案”，只复述观众的选择。

## 7. 灯光与拍摄

- 环境光压到 30%；斜板一束 3000K 暖光，屏幕不反光。
- 地面反射很强，拍摄时把相机放低，让斜板的倒影进入画面。
- 背景走廊保留，作为“真实世界”的出口，不要用背景布糊掉。

## 8. 物料清单

- [ ] 18mm 多层板 × 2 张（斜板 + 沙盘台）
- [ ] 哑光琥珀膜 / 深棕封边条
- [ ] 27" 竖屏 + 长支架 + 电源排插
- [ ] 深青灰哑光台面贴膜 + 6 格蚀刻贴纸
- [ ] 黄铜标记 × 6、玻璃弹珠 × 1
- [ ] 5cm 暖色胶带（门槛线）
- [ ] A2 三联图 1 张
- [ ] 二维码卡片 200 张
- [ ] 备用：离线演示视频 3 分钟（网络/平台故障时播放）

## 9. 兜底

- 现场网络不稳定时，用本机 `localStorage` 模式跑完整流程；屏幕右上角仍显示「本地存储」。
- 平台接口不可用时，不假装在线；直接说明“现在用的是本机数据”。
- 准备一段 3 分钟录屏，覆盖：自定义一步 → 对照 → 采纳 → 闭环归档。

## 10. 与产品 UI 的关系

- 展位用**实体斜板**；产品里只保留同源的 **`PortalSlab` 形状**（沙盘页右上角），不引用照片。
- 斜板的琥珀对应 `--step-accent` 的沙金 / 玻璃琥珀；深色屏幕对应 `#yutu2` 的深色玻璃。
- 大厅照片仅作为展陈参考，不进入 `src/assets/`；如需在路演 PPT 使用，请裁掉左侧公告板并注明“场地参考”。
