## 1. 一页纸摘要

### 1.1 一句话

**域途是一台真实环境的显影仪与决策沙盘：先定位你此刻的处境，再把处境相近者的真实经验、每一步的代价与风险摆上桌；不替你选，只让你看清楚。**

### 1.2 一句话之外的五件事

| 问题 | 域途的回答 |
|---|---|
| 我是谁、现在在哪 | 七维处境向量（年龄 / 经济 / 家庭 / 行业周期 / 认知惯性 / 体验历史 / 地域），不是一个性格标签 |
| 世界是什么样 | 46 座城市的近似结构、区域人群、256 条知乎真实原文与链接 |
| 有哪些路 | 4 个阶段合计 18 条方向，逐条列出前置条件、资源消耗、张力与代价 |
| 下一步做什么 | 体验任务（六体分类）→ 做完 → 停靠自省 → 归档 → 处境漂移 |
| 这条路值不值得 | 系统不判断。只把「起点 → 现在」的差异与「决定 → 代价」的账单摆出来 |

### 1.3 当前状态（截至 V11.19）

| 维度 | 现状 |
|---|---|
| 形态 | Web 单页应用（react-vite），HashRouter，`/#/` 即业务首页 |
| 主流程 | 4 步：填写信息 → 了解环境 → 方向与推演 → 成长闭环 |
| 附加页面 | `/#/sandbox` 沙盘推演（懒加载）、`/#/electrical` 电气实训（纯前端演示） |
| 数据 | 8 张自定义数据表、25 个 SQL 操作工作流；个人数据按本机 `ownerKey` 隔离 |
| 真实语料 | 知乎快照 256 条（14 专业大类 / 46 城市 / 4 阶段），快照时间 2026-11-19 21:46 |
| 模型 | 七维 + 加权余弦相似度 + 稳定度判定；**未用外部样本校准**，界面明示 HEURISTIC |
| 数据诚实 | 五级来源标签 + 逐图表依据审计（7 项「无外部依据」已登记缺口与补法） |
| 工程 | `type-check` / `lint` / `build` 通过；首屏主包约 340 KB（gzip 133 KB） |
| 账号 | **无独立账号体系**；换设备不合并个人数据，公共经验池不受影响 |

### 1.4 下一阶段一句话

**V12 先补证据，再做增强**：把第 1 步可观察数据补齐、把「同路人去向」从暗示变成有授权的事实、给模型一次真实校准；在这之前不新增「看起来更聪明」的功能。

## 2. 产品定位

### 2.1 定义

> 域途以多维环境向量刻画用户当前位置，以沃罗诺伊知识域组织真实经验，以阶段性胜利组织成长节奏。
> 系统由三部分咬合：**环境地图**负责定位与呈现，**经验网络**负责按处境相似度路由内容，**工作台与驿站**负责把规划变成可执行、可暂停、可改写的行动。

### 2.2 三条基本主张

1. **位置先于结论。** 一个人的可行方案，首先由所处环境约束决定；兴趣与性格是第二层筛选条件。
2. **计划是草稿。** 系统产出参考路线，不是考核指标；采用、修改、暂停的决定权在用户。
3. **胜利是阶段性的。** 生涯没有唯一终点；完成一段体验并完成自省，就是一次可被确认的胜利。

### 2.3 反「爹味规划」：界面禁令

这一节是产品与工程的共同约束，任何新功能上线前必须过一遍。

| 禁止 | 允许的替代表述 |
|---|---|
| 推荐 / 建议 / 最好 / 应该选 / 优先选 | 当前可做 / 需补条件 / 条件不足 / 前置条件是…… |
| 成功率、成功概率、成败预测 | 资源消耗、时间成本、已知风险、前置条件 |
| 你适合做什么 | 你的七维向量与哪些方向更接近；差异在哪一维 |
| 排行榜、薪资对比、结果排名 | 匿名计数、公开复盘原文、贡献概览（不排名） |
| 编造「同路人去了哪里」 | 没有该字段就说没有；有授权才展示，并标注样本量 |

系统只提供**呈堂证供**：真实原文、已知条件、资源消耗、代价与风险。定义权、评判权、选择权归用户。

### 2.4 与常见方案的区别

| 方案类型 | 起点 | 输出 | 用户角色 | 域途的差异 |
|---|---|---|---|---|
| 性格 / 兴趣测评 | 偏好 | 类型标签 | 被分类 | 以环境约束为第一变量，不用标签定义人 |
| 职业规划课程 | 通用方法论 | 课程与模板 | 学习者 | 按处境路由真实原文，不卖通用结论 |
| 招聘 / 岗位平台 | 岗位供给 | 职位列表 | 求职者 | 先问「你现在能不能走」，再谈岗位 |
| 社区问答 | 提问 | 零散经验 | 提问者 | 把经验结构化为可领取的体验任务 |
| **域途** | **处境向量** | **定位 + 真实经验 + 可执行下一步 + 代价账单** | **决策者** | **不替用户下结论；计划可改写** |

### 2.5 明确的非目标

- 不做心理诊断、不做临床量表、不输出人格类型。
- 不做成功率预测、不做「哪条路更好」的排序。
- 不做招聘撮合、不做薪资比较、不做成功学内容分发。
- 不做实时爬虫；语料是显式快照，快照时间可见。
- 不做运行时大模型直答（当前版本）；未接入前不假装有。

## 3. 用户与场景

### 3.1 三类核心用户

| 阶段 | 典型画像 | 此时最痛的问题 | 域途提供的第一个抓手 |
|---|---|---|---|
| 在校探索期 `explore`（16–23） | 在校高年级 / 即将毕业 | 方向太多、信息太杂，不知道先试什么 | 七维定位 + 方向清单 + 一条低成本的体验任务 |
| 初入职场期 `entry`（22–27） | 工作 1–5 年，第一份工作定调 | 对口岗位的真实日常与预期不符 | 二阶检索 + 作战图代价 + 可迁移能力盘点 |
| 转向抉择期 `pivot`（26–33） | 已有存量经验，考虑转行 | 存量经验能不能迁移、窗口还剩多久 | 归属摘要 + 过渡带 + 沙盘推演 |
| 稳态深耕期 `anchor`（32–45） | 家庭与现金流约束变硬 | 不能归零重来，只能做增量 | 资源约束下的沙盘 + 阶段性胜利归档 |

> 阶段由年龄、身份与七维共同判定，但**不作为标签展示**；界面只显示「当前阶段」与判定依据，用户可回第 1 步修改。

### 3.2 非目标用户

- 期待系统直接给出「你该去哪、该做什么」的人。
- 需要即时职位投递或薪酬谈判的人。
- 需要心理干预或危机支持的人（应转向专业机构）。

### 3.3 典型旅程

**首次 15 分钟**

```
第 1 步 填写信息（约 6 分钟）
  → 七维向量 + 阶段判定 + 填写质量
第 2 步 了解环境（约 3 分钟）
  → 定位城市 → 区域圈 → 人群 → 证据 → 原文
第 3 步 方向与推演（约 5 分钟）
  → 方向清单 → 选一条 → 二阶深挖 → 代价与清单 → 归属摘要
第 4 步 成长闭环（约 1 分钟）
  → 领取 1 条体验任务，离开
```

**一轮闭环（1–4 周）**

```
体验任务（doing） → 标记完成（done） → 停靠自省（三问）
  → 归档（keep / revise / rest / switch） → 处境漂移 ΔS
  → 回看落点：方向是否改变？
      ├─ 没变：继续本轮 / 开启下一轮
      └─ 变了：回第 1 步重填（历史记录保留）
```

**沙盘支线（10 分钟）**

```
#/sandbox → 6 格 × 1 季度 = 18 个月
  → 预设动作 或 写下自己的路（投入强度 + 六体分类）
  → 真实原文检索 + 资源消耗（不推断七维变化）
  → 与「维持现状」三栏对照
  → 采纳为计划 → 最多 4 条体验任务写入工作台
```

### 3.4 Jobs to be Done

1. 当我站在十字路口时，帮我**看清自己站在哪**，而不是先给我一个标签。
2. 当别人说「这条路好」时，帮我看**这一步具体要付什么**。
3. 当我做了一段时间后，帮我**对比起点与现在**，判断是否还要继续。
4. 当我停下来时，允许我**暂停而不被判定为失败**。

## 4. 产品结构与功能说明

### 4.1 信息架构

```
/#/                      四步主流程（业务首页）
  ├─ STEP 01 填写信息
  ├─ STEP 02 了解你所处的环境
  ├─ STEP 03 方向与推演
  │    ├─ 01 方向清单
  │    ├─ 02 二阶深挖（右侧抽屉 / 移动端底部 sheet）
  │    └─ 03 归属与摘要（含资源作战图）
  └─ STEP 04 成长闭环
       ├─ 01 闭环顺序（当前步骤 + 完整六步）
       ├─ 02 闭环全貌（螺旋年轮）
       ├─ 03 本轮工作区（体验工作台 / 停靠驿站）
       └─ 04 档案与同伴（档案墙 / 同伴经验域）
/#/sandbox               沙盘推演（独立页，共用数据层）
/#/electrical            电气实训（纯前端演示，不挂数据层）
```

**两大板块**（Shell 顶部）：

- **我的处境**：第 1–3 步，只读投影，不产生 `ΔS`。
- **我的成长**：第 4 步，唯一产生处境漂移的地方。

**编号三级制**（V11.13 统一）：

- 页面级：`STEP 0N · 名称`
- 板块级：`0N / 名称`
- 局部流程：`① ② ③`

### 4.2 STEP 01 填写信息

**目的**：把「我是谁」从主观描述变成可核对的结构化事实。

| 区块 | 内容 | 输出 |
|---|---|---|
| 基本事实 | 常住城市、年龄、城乡、身份（学 / 工）、所学或所从事方向 | 事实字段 |
| 结构化测量 | 经济、家庭、行业周期、探索行为、体验历史 | 可观察指标 + 透明公式 |
| 校准量表 | 用户可手动覆盖计算结果 | 明确提示「覆盖计算」 |
| 判定结果 | 七维向量、阶段、填写质量（完整度 + 一致性） | 进入下一步的依据 |

**交互要点**

- 顶部「快速定位」：基本事实 / 结构化测量 / 校准量表 / 判定结果，`scrollIntoView` 并预留吸顶高度。
- 「显影」反馈：配图初始 66% 不透明 + 低饱和，用户首次聚焦 / 点击 / 输入后 1s 内变清晰；文案「你每写下一项，这张图就清晰一点。」
- 至少填写一个方向才允许进入下一步；其余步骤以「继续」作为完成动作。
- 修改后可通过已解锁页签或「下一步」跳回后面，不丢数据。

**数据边界**：写入个人档案表（当前表 ID 8766）；首次进入生成 `ownerKey` 并持久化在本机。

### 4.3 STEP 02 了解你所处的环境

**目的**：用「结论 → 定位 → 人群 → 证据 → 原文」五段式，让用户先看清外部约束。

| 模块 | 说明 | 数据分级 |
|---|---|---|
| 区域结论 | 城市能级、产业密度、生活成本档位 | APPROX（城市属性近似） |
| GIS 地图 | Leaflet + OpenStreetMap，46 城可点选，277 km 区域圈，地理 / 网络双模式 | APPROX + 离线 Natural Earth 矢量 |
| 区域构成 | 圈内城市、岗位密度分级、邻近关系 | APPROX |
| 近期讨论 | 与所选方向相关的知乎原文摘要 + 原文链接 | REAL（快照，不运行时检索） |
| 数据来源 | 页头快照时间 + 每条数据挂来源徽标 | 五级来源 |

**口径纪律**

- 地图飞线只表示**岗位密度 / 资料归属 / 邻近关系**，不表示「同路人的真实下场」。
- 底图加载失败时保留离线矢量陆地并提示「离线矢量底图」，不白屏。
- 检索不到时如实显示「没有检索到直接相关的原文」，不用通用内容伪装。

### 4.4 STEP 03 方向与推演

**目的**：把「有哪些路」拆成三件事——有什么、深挖什么、要付什么。

#### 4.4.1 方向清单

- 4 个阶段合计 18 条方向；每条含：名称、可行性、前置条件、资源消耗、张力。
- 可行性由显式 `traits`（`job` / `cash` / `time` / `reset`）判定，不用方向名正则。
- 方向卡按名称稳定哈希分配玻璃色，选中铺满整条；侧栏五色玻璃轨。
- 候选短名单最多 4 条，供第 4 步之前并排对比。
- 「你的想法」为折叠块：默认摘要，展开后编辑；填写后参与检索。

#### 4.4.2 二阶深挖

- 点击「选它 · 二阶深挖 / 继续深挖」打开右侧抽屉（移动端底部 sheet）。
- 抽屉内复用 `SecondStageSearch`：更具体的问题、原文、链接、代价提示。
- 结果里的「去作战图看执行清单」关闭抽屉并切到作战图。
- 支持关闭按钮、背景点击、Esc。

#### 4.4.3 作战图

- Leaflet GIS，按 55 / 105 / 155 km 三层推进圈排布方向节点。
- 每个方向带扇区、推进飞线；资源仓显示一次性资源存量。
- 方向 → 资源的补给线、方向之间的张力线可独立开关。
- 飞线动画只表示推进 / 补给方向，**不代表速度、成功率或优先级**。
- 点击节点联动右侧「代价明细」，可回到我的城市。

#### 4.4.4 归属与摘要（SET 视图）

- `d3-delaunay` 计算真实 Voronoi 单元，可点击切换参考域。
- 右侧域解读、七维雷达、逐维贡献、相似域 Top 4、稳定度、过渡带。
- 明确提示「二维投影 ≠ 七维归属」。
- 归档后的向量快照绘制为历史漂移轨迹，可开关。
- 「一页纸摘要」：浏览器本地生成 Markdown / `.json`，可复制或下载。
- 底部主按钮直接进入第 4 步；进入时用共享元素过渡（方向 chip 连续移动）。

### 4.5 STEP 04 成长闭环

**目的**：把计划变成可完成、可暂停、可归档的一轮，并把经验留给后来者。

#### 4.5.1 闭环六站点

```
领取任务 → 去体验 → 标记完成 → 停靠自省 → 归档漂移 → 回看落点
```

- 环图从「圆环 + 绕圈弹珠」改为「螺旋年轮」：外圈当前轮，内圈已完成轮次（最多 3 圈 + 中心计数）。
- 当前站点琥珀节点 + 弹珠「你在这里」；下一站虚线环；未来站点低对比。
- 常驻动画每区域 ≤ 2 个；减动效 / 动效关下停止。
- 六站点默认收进「完整六步」折叠，当前步骤卡承担唯一主 CTA。

#### 4.5.2 体验工作台

- 任务来自：方向节点生成、沙盘采纳、用户自定义。
- 六体分类；状态 `doing / done / hold / drop`。
- 首次标记 `drop` 时应用「放弃漂移」：体验历史 +2、认知惯性 −1；同一任务反复开关只计一次（本机记录，上限 400 条）。
- 无已完成体验时归档按钮禁用，并提供「去工作台标记完成」。

#### 4.5.3 停靠驿站

- 三问自省（`q1 / q2 / q3`）+ 下一步选择：`keep / revise / rest / switch`。
- 归档时保存**归档前**向量快照到胜利档案；归档后把漂移写回个人档案，形成「过去 → 现在」证据链。
- 「休整」不推送新任务，只回工作台。
- 归档完成卡与总览横幅会问「你要走的方向是否发生变化？」：
  - 没变：有未归档任务则继续本轮，否则开启下一轮；
  - 变了：回第 1 步重填，平台记录与历史档案保留。

## 5. 模型与数据口径

### 5.1 七维处境向量

| 维度 | 含义 | 采集方式 | 来源分级 |
|---|---|---|---|
| `age` | 年龄 | 用户填写 | 事实 |
| `place` | 经济压力 / 可支配缓冲 | 结构化测量（收入稳定性、储蓄、负债、支出） | SELF |
| `family` | 家庭责任 | 结构化测量（赡养、抚养、异地、支持度） | SELF |
| `cycle` | 行业周期 | 结构化测量（招聘景气、岗位收缩、技能折旧） | SELF + APPROX |
| `inertia` | 认知惯性 | 结构化测量（信息源多样性、探索频率、沉没成本感） | SELF |
| `history` | 体验历史 | 结构化测量（相关经历、试错次数、可迁移成果） | SELF |
| `urban` / `ident` / `field` / `city` | 城乡、身份、方向、城市 | 基本事实 | 事实 / APPROX |

> 当前是**七维**，不是早期文档中的四维雷达。四维表述已废弃。

### 5.2 相似度与稳定度

**综合相似度**

```
similarity = (0.75 × 方向带权余弦 + 0.25 × 强度接近度) × √min(1, |v| / 0.5)
```

- 方向仍主导；强度项解决「只比方向、不比强度」。
- 收缩项让信息不足的用户显示「尚未落定」，而不是一个看似确定的高百分比。

**稳定度**

- 绝对差用于界面展示；相对差 `(S1 − S2) / S1` 用于判定：高 ≥ 0.15，中 ≥ 0.06。
- 模长 < 0.35 直接判低，并提示按过渡带理解。
- 过渡带阈值 `bandEps = 0.06`（综合相似度绝对差）。

**未校准声明（必须出现在界面与文档）**

- 权重、阈值、公式均为启发式缺省，**未用外部样本校准**。
- 界面统一挂 HEURISTIC 徽标；不得表述为「科学测评」或「精准匹配」。

### 5.3 Voronoi 域与公共节点

- 每个方向节点是一个种子；Voronoi 单元表示「在七维空间里离它最近的范围」，是**相似度分配 + 可视化隐喻**。
- 复盘升级为公共节点是**派生规则**，不新增表：`marks >= 3` 且取标记数最高的 8 条。
- 自己的节点（`author_key === ownerKey`）不参与自己的归属计算。
- 公共节点参与他人归属；这构成外层「经验共建闭环」。

### 5.4 SET 模型映射

| 段 | 含义 | 代码映射 |
|---|---|---|
| **S** Situation | 七维处境 + 阶段 | `profile.s` + `currentStage` |
| **C** Constraint | 方向可行性 | `feasibility` + `traits` |
| **R** Reference | 相近经验 | `ranked` / `similarityOf` + `reviews` / `marks` |
| **T** Transition | 归档漂移 | `DRIFT` / `DROP_DRIFT` / `archive` / `applyInactivityDecay` |

第 3 步的「归属与摘要」按 SET 四段式呈现，作为进入闭环前的最后一次确认。

### 5.5 漂移与衰减

| 事件 | 效果 | 持久化 |
|---|---|---|
| 归档 `keep / revise / rest / switch` | 按 `DRIFT` 表应用 `ΔS`，写回个人档案 | 平台档案表 + 本机快照 |
| 首次放弃任务 | 体验历史 +2、认知惯性 −1 | 平台任务状态 + 本机去重记录 |
| 30 天无新归档 | 体验历史与认知惯性小幅衰减 | 本机计算，界面明示 |

> 漂移是**规则**，不是预测。界面不展示「按此发展你会怎样」。

### 5.6 数据来源五级

| 分级 | 含义 | 示例 |
|---|---|---|
| REAL | 真实公开原文快照 | 知乎回答 / 文章 + 原文链接 |
| SELF | 用户自己填写 | 七维测量、三问自省 |
| CURATED | 人工配置的案例 / 资源规则 | 精编案例、方向前置条件 |
| APPROX | 近似属性 | 城市能级、岗位密度、经纬度 |
| HEURISTIC | 系统规则推导 | 相似度、稳定度、沙盘效果、现金 / 精力 |

**逐图表依据审计**（`src/data/evidence-audit.ts`）：每张图表登记名称、页面、来源类型、状态（`grounded / partial / unfounded`）、界面位置、来源说明、缺口、补法、是否可在第 1 步补数据。

当前「无外部依据」7 项：

1. 归属相似度 / 稳定度
2. 长期记忆接近度
3. 沙盘预设动作效果
4. 沙盘现金 / 精力推导
5. 沙盘维持现状
6. 沙盘落点
7. 新用户初始档案

### 5.7 两条不同的门槛（不混用）

| 门槛 | 作用对象 | 规则 | 执行时机 |
|---|---|---|---|
| 内容配置门槛 | 参考草稿 / 精编案例 | 同一路线至少 2 个独立来源交叉印证，孤证不生成草稿 | 内容运营阶段 |
| 公共节点门槛 | 用户复盘 | 至少 3 个不同用户标记有效 | 运行时派生 |

### 5.8 两条硬边界

1. **没有「同路人去向城市」字段**。现有表只记录作者处境城市与下一步选择，地图飞线不得声称是「同路人的真实下场」。要落地必须先新增去向字段 + 明确授权。
2. **没有运行时大模型 RAG 直答**。当前是「真实语料检索 + 固定规则」，不是生成式推演；不得用通用内容伪装成按方向检索。


**禁令**：组件禁止直接 `fetch`，禁止消费后端列名。新接口按「建表 → 建 SQL API → 登记 `.project.md` → `yutuApi` → Context → 组件」顺序挂载。

- 「我的数据」可导出完整 JSON，便于迁移或删除。

### 6.5 降级与容错

| 场景 | 行为 |
|---|---|
| 无平台页面代理（本地 dev） | 自动切 `localStorage` 快照（`yutu.state.v3`），顶部显示「本地存储模式」 |
| 初始化多个读接口 | `Promise.allSettled`，部分失败不整体降级 |
| 写接口失败 | 退回本机，不丢正在填写的内容 |
| 地图瓦片失败 | 保留离线矢量陆地 + 提示，不白屏 |
| 渲染异常 | 路由级 `ErrorBoundary`，提供恢复入口 |
| 沙盘 / 二阶检索 | 路由级 / 组件级懒加载，不阻塞首屏 |
| 不支持的浏览器特性 | View Transition / IntersectionObserver 缺失时降级为直接切换 |

### 6.6 隐私与合规

- 七维涉及经济、家庭等敏感信息，默认只存个人档案，不进入公共检索。
- 公共内容写入前 `desensitize`；素材只收公开链接，不收文件。
- 不展示薪资、结果排名、成功率。
- 用户可导出 / 清除本机数据；平台数据可通过界面删除自己的复盘、讨论、素材。
- 知乎内容按公开快照使用，来源与时间可见；不复刻原文全文，只展示摘要与链接。

## 9. V12 迭代计划

### 9.0 计划原则

1. **先补证据，再做增强。** 没有来源支撑的可视化，不加。
2. **先修暗示，再加功能。** 任何可能被误读为「预测 / 推荐」的文案与图形优先处理。
3. **能降级，才算完成。** 每个新功能必须有离线 / 失败态。
4. **不引入新框架，不改变模版类型。** 继续 react-vite + HashRouter。
5. **每项交付必须带验收口径与证据位置。**

### 9.1 P0：数据诚实与入口收敛（建议 4 周）

| 编号 | 事项 | 范围 | 验收标准 | 依赖 / 风险 |
|---|---|---|---|---|
| P0-1 | 第 1 步补 4 个可观察字段 | 档案表新增「可动用现金可撑月数 / 每周可投入小时 / 赡养抚养人数 / 行业招聘景气」；同步 `profile_save` 与 `profile_get` 入参；评估公式与 `evidence-audit` 更新 | 新字段可在第 1 步填写并回读；旧用户缺字段时有默认值与提示；审计面板相应项从「unfounded」转为「partial / grounded」 | 需改表结构与工作流；平台无删除接口，先设计好列名与类型 |
| P0-2 | 同路人去向：从暗示到事实 | 方案 A：新增去向城市字段 + 显式授权开关 + 样本量门槛（≥N 才画）；方案 B：若本期不做，移除所有可被读成「真实去向」的飞线文案与图例 | 界面不再出现无依据的「同路人去了哪」暗示；有授权时展示样本量与快照时间 | 涉及隐私与授权文案；样本不足时必须有空态 |
| P0-3 | 模型校准 | 收集 50–100 份标注样本（方向归类的专家 / 从业者判断），计算一致性；输出校准报告 | 报告中给出当前权重下的一致率与混淆点；未达标则在所有相关图表继续挂 HEURISTIC，并写明校准日期与样本量 | 样本获取是外部依赖；不得用自评数据冒充专家标注 |
| P0-4 | 可达性回归 | 键盘全流程、焦点顺序、焦点可见、对比度、屏幕阅读器标签、表单错误播报 | 完成一份键盘走查记录；关键流程无键盘陷阱；对比度达到 WCAG AA（正文） | 需要真机 / 读屏工具；视觉改动需回归暗色玻璃 |

**P0 完成定义**：四项都有可核对的证据（截图 / 记录 / 报告），且 `type-check` / `lint` / `build` 通过。

### 9.2 P1：闭环留存与共建质量（建议 4–8 周）

| 编号 | 事项 | 说明 | 验收标准 |
|---|---|---|---|
| P1-1 | 轻量跨设备 | 账号体系或「迁移码 / 导入导出」二选一；优先做导入导出闭环 | 新设备可通过导出文件恢复档案 / 任务 / 档案；合并冲突有明确规则 |
| P1-2 | 复盘结构化模板 | 在自由文本之外提供可选结构：做了什么 / 花了多久 / 遇到什么 / 结果如何 / 若重来会改什么 | 模板不强制；提交后公共池可按字段筛选（不排名） |
| P1-3 | 讨论质量工具 | 举报、折叠、作者删除、敏感词提示；不做算法推荐 | 被折叠内容默认隐藏；作者可删除自己的讨论；有操作记录 |
| P1-4 | 沙盘 → 计划草稿 | 采纳后生成「计划草稿」视图（时间线 + 任务 + 成本），仍不推断七维 | 草稿可编辑、可删除；与工作台任务双向可追溯 |

| P2-3 | 隐私友好埋点 | 只统计漏斗与失败率，不采集正文与七维原值 | 埋点清单公开；可一键关闭 |

## 11. 风险与对策

| 风险 | 表现 | 对策 |
|---|---|---|
| 伦理风险：被读成「人生规划器」 | 用户期待系统给答案 | 全站禁令措辞；空态与边界提示；演示脚本先讲「不做什么」 |
| 内容偏差 | 知乎样本幸存者偏差、片面经验 | 五级来源；2 源配置门槛；公共节点 3 人门槛；原文链接可核对 |
| 模型误导 | 相似度高被当作「适合」 | HEURISTIC 徽标；稳定度与过渡带；不做成功率 |
| 隐私 | 经济 / 家庭数据敏感 | 只存个人档案；公共内容脱敏；素材只收公开链接；可导出删除 |
| 平台依赖 | 工作流不可用 / 重建 | 本机降级；`Promise.allSettled`；token 集中映射；`.project.md` 登记 |
| 演示现场 | 网络 / 瓦片 / 接口失败 | 离线矢量底图；本机快照；预置演示数据；断网演练 |
| 合规 | 知乎内容使用边界 | 只存摘要与链接；快照时间可见；不转售、不全文复刻 |
| 范围膨胀 | 想加推荐 / 预测 / 排名 | 第 9.5 节「本期明确不做」；新需求先过第 2.3 节禁令 |
