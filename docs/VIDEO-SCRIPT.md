> 用途：知乎黑客松 S3 选交材料「项目演示视频」。
> 目标：3 分钟内让评委看懂「这是什么、解决什么问题、怎么用、凭什么可信」。
> 录制地址：优先平台 `prod` 链接（数据完整）；GitHub Pages 版可作备用（跨用户内容为空，需避开同伴池镜头）。

## 0. 一句话策略

全程避免出现「AI 帮你决定」的说法；每个镜头都指向「显影、对照、代价、下一步」。

## 2. 旁白全文（可直接朗读，约 640 字）

> 域途，一台真实环境的显影仪。它不告诉你该去哪。
>
> 「泻水置平地，各自东西南北流」。每个人被放到地上，流向了不同的方向。问题不是谁流得更远，而是你现在站在哪块地上。
>
> 域途用七个维度描述你此刻的处境：年龄、经济、家庭、行业周期、认知惯性、体验历史、地域。不是一个性格标签。
>
> 先选城市和年龄。城市决定机会密度，年龄决定你能承担的时间成本。量表不是考试，它只检查一件事：你的回答有没有自相矛盾。有矛盾，它会指出来，而不是替你圆过去。方向必须自己填。域途不替你选。
>
> 了解你所处的环境。同样是三十岁，在核心区和在县域，能走的路完全不同。飞线只表示信息密度，不代表去向。每一条讨论都能点回知乎原文，页头写着快照时间。
>
> 这些方向不是模板，是从真实经验里抽出来的。每一条都列清前置条件、要付出的代价、可能踩的坑。想深挖一条路，可以再检索一次。域途只做索引，不下结论。
>
> 最后是归属摘要：你和哪些处境更接近，相似度是多少，以及——它不参与你自己的判断。
>
> 这是沙盘。六个格子，每个代表一个季度。你可以先推演，再决定要不要真的走。规则是确定的，没有随机。两种走法的投入、时间成本、检索原文，并排放在一起。选哪个仍然由你。
>
> 做完一件事，回来停靠、自省、归档。每一个结论下面，都标着它的来源等级。我们不假装知道得比实际更多。

## 3. 录制准备清单

- [ ] 平台 `prod` 链接已在无痕窗口验证可打开
- [ ] 准备一组「演示数据」：城市 = 深圳，年龄 = 27，身份 = 工作，方向 = 转行做产品
- [ ] 提前跑一遍全流程，确认地图瓦片加载正常（失败则改用「离线矢量陆地」并口播说明是设计内降级）
- [ ] 关闭浏览器通知、书签栏、扩展图标
- [ ] 系统声音关闭（旁白后期配）；开篇若保留原声，单独录一条
- [ ] 录屏工具：1080p / 30fps / 硬件编码；先完整录一遍无声

## 4. 后期建议

| 项 | 建议 |
|---|---|
| 节奏 | 每段之间留 0.3–0.5s 黑场，避免跳切 |
| 字幕 | 全片加大字幕（评委常在静音下看）；关键词高亮：显影 / 代价 / 不替你选 |
| 音乐 | 极轻的钢琴或环境音，音量 −24dB，不能盖过旁白 |
| 重点标注 | 第 4、9、11 镜加箭头或圆圈标注，指向「矛盾提示」「代价清单」「来源等级」 |
| 结尾 | 黑底 3 秒：作品名 + 公网链接 + 二维码 |

## 6. 常见翻车点

| 风险 | 规避 |
|---|---|
| 地图瓦片被网络拦截 | 录制前单独测一遍；失败就口播「离线降级」 |
| 同伴域为空（GitHub Pages 版） | 用平台 prod 录制，或跳过该镜头 |
| 开篇动画太长导致超时 | 视频里保留 8.65s 完整开篇，其他镜头压缩 |
| 旁白说成「AI 建议你」 | 全片禁用「建议 / 推荐 / 应该」，只用「显影 / 对照 / 可以看到」 |
