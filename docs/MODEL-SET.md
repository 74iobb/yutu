# SET 模型：Situation–Experiment–Transition

> 本文是域途的正式工程模型说明，用来替代“沃罗诺伊图 / 雷达图”这类只承担视觉解释、不承担计算的表述。
> 模型的目标不是预测结果，而是把“处境 → 约束 → 试验 → 迁移”变成可计算、可解释、可验证、可更新的闭环。

## 1. 为什么需要这个模型

此前第五步用二维沃罗诺伊图和七维雷达图解释归属，但它们有两个根本问题：

- **不参与计算**：二维投影是手选两轴，不是真实降维；雷达只呈现形状，不呈现权重。
- **容易被过度解读**：面积、形状、单元大小都没有统计意义，却看起来像结论。

SET 模型把真正参与计算的量说清楚，界面只呈现模型里的状态、约束、来源与迁移。

## 2. 四个组件

### 2.1 Situation（处境 S）

```text
S_t = (place, econ, family, age, cycle, inertia, history, stage)
```

- 七维连续值；`age` 归一化后参与计算，展示时保留原始岁数。
- `stage` 由身份、年龄、体验历史决定，不是用户自选。
- 用户可手动校准；每次归档保存前后快照。

### 2.2 Retrieval（相近经验 R）

```text
R(S_t) = top-k { experience | sim(S_t, S_exp) 高，且来源可追溯 }
```

- `sim` 使用综合相似度：方向余弦 + 强度接近度 + 低信息收缩。
- 每条经验必须带：作者处境、来源、前置条件、风险；不保证结果。
- 经验不按“兴趣标签”路由，只按处境相似度路由。

### 2.3 Experiment（试验 E）

```text
C(S_t) = { d ∈ Directions | feasibility(d, S_t) ≠ low }
E_t = decompose(d_t, S_t) → { task_1 ... task_n }
```

- 可行性由显式条件标签判定：`job / cash / time / reset`，配合城市、经济、家庭、年龄阈值。
- 任务是六体分类下的最小线下体验，必须可完成、可检查。
- 方向不是“最优解”，是“当前可承受的试验”。

### 2.4 Transition（迁移 T）

```text
choice_t ∈ { keep, revise, rest, switch }
ΔS_t = drift(choice_t)
S_{t+1} = clamp(S_t + ΔS_t + decay(Δt))
```

- 归档选择决定漂移方向；漂移是模型参数，可用真实归档前后向量校准。
- 超过 30 天无归档时，体验历史与认知惯性小幅衰减。
- 胜利档案保存 `S_t`（归档前）与 `S_{t+1}`（归档后），形成可回看的轨迹。

## 4. 可验证性

1. **ΔS 校准**：用真实归档前后向量回归 `choice → ΔS`，替换手写系数。
2. **C 校准**：请咨询师标注“可做 / 需补条件 / 不建议”，校准阈值。
3. **R 校准**：用“是否点开、是否标记有效”验证相似度排序的有效性。
4. **E 验证**：任务领取率、完成率、归档率；低于阈值说明任务拆得不对。
5. **T 验证**：归档后方向是否改变、下一次选择是否更聚焦。

当前状态：以上均为**待校准**；界面与文档必须明示，不得包装成已验证结论。

## 5. 界面表达

第五步不再画沃罗诺伊/雷达，按模型四段呈现：

1. **S 处境**：七维条 + 阶段；
2. **C 约束**：方向可行性清单；
3. **R 经验**：同阶段真实复盘 + 自己的历史档案；
4. **T 迁移**：最近一次归档的前后变化 + 逐维贡献 + 进入下一轮。

每一行都能回答“它从哪来、为什么在这里”，不靠形状暗示结论。

## 6. 与理论的关系

- 库伯循环 = E（体验）→ 反思 → 概念化 → 再试验；
- Super 生涯发展理论 = 阶段与多角色，解释 S 为什么变化；
- 黄天中体验式生涯规划 = 四生五业六体，提供任务分类与判断视角。

SET 是工程模型，负责把理论变成状态转移；理论负责解释为什么这样设计。

## 7. 边界

- 不预测成功率、不做人格测评、不打分。
- 归属是相似度路由，不是分类标签。
- 权重与阈值是启发式缺省，未外部校准。
- 同阶段统计只代表“归档时的决定”，不是日常行为。
- 经验池与任务供给需要真实服务场景承接，不能只靠软件。
