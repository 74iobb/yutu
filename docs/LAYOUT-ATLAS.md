## 2. 开篇 Overture（覆盖层）

```
全屏遮罩（白 / 银 / 浅金日光）
├─ 取景框四角 + 左「域途 · 序」 + 右「YUTU / OVERTURE」
├─ 场景（10:9，等比缩放，不裁切）
│  ├─ 日光天空 / 暖金光晕 / 体积光 / 丁达尔神光
│  ├─ 镜面水面：黑曜石底、油膜、焦散、剪影人
│  ├─ 水束 18 根 + 下落水粒 + 溅水 + 悬浮微尘 + 落点水沫
│  ├─ 撞击高光：冲击波 / 横向镜头光斑 / 四芒星
│  ├─ Voronoi 四板块 + 方向光轨 + 星尘
│  └─ 名句两行（逐字金→冷白）+ 小字 + 落款
└─ 底部：声音提示（被拦截时）/ 右下「声音 开/关」「跳过」
```

- 时长：约 7.8s 正片 + 1.15s 退潮；点击 / 任意键跳过；Tab 保留。
- 退场：水束倒收、水面下沉、水线外扩、标签四散；音乐/录音/语音硬停。

## 10. 状态与边界

- 空态：工作台、档案墙、同伴经验域、沙盘结果区均有明确空态 + 下一步。
- 加载：懒加载步骤有「正在加载内容…」；地图有离线/失败回落。
- 离线：自动切本机缓存，头部显示「本地存储模式」；写失败有提示。
- 首用：无消息干扰；未填写时判定卡「尚未判定」。
- 移动端：单列、侧栏后置、棋盘横向滚动、按钮全宽。
- 无障碍：跳过链接、焦点可见、装饰层 `aria-hidden`/`pointer-events:none`、开篇期间主界面 inert。
