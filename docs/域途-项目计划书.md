## 1. 执行摘要

### 1.1 一句话

**域途是一台真实环境的显影仪与决策沙盘：先定位你此刻的处境，再把处境相近者的真实经验、每一步的代价与风险摆上桌；不替你选，只让你看清楚。**

### 1.2 问题与方案

高考择校、考研择校、毕业 1–3 年转行、跨城市迁徙，是知乎上提问最密集、也最容易「答案很多但不知道信谁」的场景。传统工具从兴趣或性格测评出发，回答「你适合什么」，却回答不了三个更现实的问题：**我现在能不能走、这一步具体要付什么、走了一段之后要不要继续**。

域途把这三个问题拆成一条可执行的主流程：

1. **定位**：用七个维度描述「你现在在哪」，而不是用标签定义「你是谁」。
2. **看清环境**：以地图、区域结构、真实原文呈现外部约束与可选方向。
3. **先推演**：在沙盘里把一条路走一遍，把时间、现金、精力摊开对照。
4. **小步验证**：领一条低成本的体验任务，做完后自省、归档，让处境发生可解释的漂移。

### 1.3 当前进展（可演示、可核对）

| 维度 | 现状 |
|---|---|
| 形态 | Web 单页应用（`react-vite` 模版），HashRouter，`/#/` 即真实业务首页 |
| 主流程 | 4 步：填写信息 → 了解环境 → 方向与推演 → 成长闭环 |
| 附加页面 | `/#/sandbox` 沙盘推演（独立路由，共用数据层） |
| 数据 | 8 张自定义数据表、25 个 SQL 操作工作流；个人数据按本机 `ownerKey` 隔离 |

**V12 先补证据，再做增强。** 先把第 1 步可观察数据补齐、把「同路人去向」从暗示变成有授权的事实、给模型一次真实校准；在这之前不新增「看起来更聪明」的功能。

## 2. 项目背景

### 2.1 三类真实决策场景

| 场景 | 典型问题 | 现有工具的缺口 |
|---|---|---|
| 高考 / 考研择校 | 城市、学校、专业、成本怎么权衡 | 排名多、代价少；很少回答「以你的家庭现金流能撑多久」 |
| 毕业 1–3 年转行 | 存量经验能否迁移、窗口还剩多久 | 课程多、真实路径少；成功案例不可核对 |
| 跨城市迁徙 / 阶段性复盘 | 换城市的机会密度、生活成本、家庭约束 | 岗位列表多、结构信息少；缺少可暂停的节奏 |

这些问题的共同点是：**答案高度依赖处境**。同一个「转行互联网」的建议，对需要尽快赚钱的人与可以脱产学习的人，代价完全不同。

### 2.2 传统生涯规划的三个失效环节

1. **定位失效。** 多数工具以兴趣测评或性格类型作为起点，输出「你适合什么」。测评回答的是偏好，不是可行性；偏好相同的人，可行路径可能完全相反。
2. **信息与沉淀失效。** 通用方法论缺少「这一步具体怎么做、要花多久、会遇到什么」的细节；即便有人走通，经验也不会被系统记住并传递给下一个处境相似的人，每次探索都从零开始。
3. **节奏失效。** 规划被写成跨越数年的整体目标，中间没有检查点，也没有为停顿留位置。人要么长期看不到反馈，要么发现走不通时已没有调整余地。

### 2.3 现有工具的共性偏差

| 方案类型 | 起点 | 输出 | 用户角色 | 域途的差异 |
|---|---|---|---|---|
| 性格 / 兴趣测评 | 偏好 | 类型标签 | 被分类 | 以环境约束为第一变量，不用标签定义人 |
| 职业规划课程 | 通用方法论 | 课程与模板 | 学习者 | 按处境路由真实原文，不卖通用结论 |
| 招聘 / 岗位平台 | 岗位供给 | 职位列表 | 求职者 | 先问「你现在能不能走」，再谈岗位 |
| 社区问答 | 提问 | 零散经验 | 提问者 | 把经验结构化为可领取的体验任务 |
| **域途** | **处境向量** | **定位 + 真实经验 + 下一步 + 代价账单** | **决策者** | **不替用户下结论；计划可改写** |

共性偏差在于：把「计划」当成产品，把「人」当成执行计划的载体。产品越做越像一份更精致的报告，用户的参与止步于阅读。而生涯的本质，是学习者在真实世界里不断体验、反思、修正的过程。

### 2.4 机会窗口

- **内容基础已经存在**：知乎沉淀了大量真实经历与可追溯的讨论，缺的是「按处境路由 + 可执行转译」。
- **决策正在变短**：一次性规划越来越难成立，用户需要的是可暂停、可改写的小步验证。
- **AI 能力已可用但需克制**：检索、结构化、引用可以增强可信度；未经校准的生成式建议会放大误导。域途选择先把数据与规则做诚实，再引入生成能力。

> 本项目不引用未经核实的市场规模数字。需求判断以可观察的问题密度、现有工具的共性缺口与真实语料为依据。

## 3. 产品定位

### 3.1 定义

> 域途以多维环境向量刻画用户当前位置，以沃罗诺伊知识域组织真实经验，以阶段性胜利组织成长节奏。
> 系统由三部分咬合：**环境地图**负责定位与呈现，**经验网络**负责按处境相似度路由内容，**工作台与驿站**负责把规划变成可执行、可暂停、可改写的行动。

### 3.2 三条基本主张

1. **位置先于结论。** 一个人的可行方案，首先由所处环境约束决定；兴趣与性格是第二层筛选条件。
2. **计划是草稿。** 系统产出参考路线，不是考核指标；采用、修改、暂停的决定权在用户。
3. **胜利是阶段性的。** 生涯没有唯一终点；完成一段体验并完成自省，就是一次可被确认的胜利。

### 3.3 反「爹味规划」：界面禁令

这一节是产品与工程的共同约束，任何新功能上线前必须过一遍。

| 禁止 | 允许的替代表述 |
|---|---|
| 推荐 / 建议 / 最好 / 应该选 / 优先选 | 当前可做 / 需补条件 / 条件不足 / 前置条件是…… |
| 成功率、成功概率、成败预测 | 资源消耗、时间成本、已知风险、前置条件 |
| 你适合做什么 | 你的七维向量与哪些方向更接近；差异在哪一维 |
| 排行榜、薪资对比、结果排名 | 匿名计数、公开复盘原文、贡献概览（不排名） |
| 编造「同路人去了哪里」 | 没有该字段就说没有；有授权才展示，并标注样本量 |

系统只提供**呈堂证供**：真实原文、已知条件、资源消耗、代价与风险。定义权、评判权、选择权归用户。

### 3.4 明确的非目标

- 不做心理诊断、不做临床量表、不输出人格类型。
- 不做成功率预测、不做「哪条路更好」的排序。
- 不做招聘撮合、不做薪资比较、不做成功学内容分发。
- 不做实时爬虫；语料是显式快照，快照时间可见。
- 不做运行时大模型直答（当前版本）；未接入前不假装有。
- 不做社交关注、私信、排行榜。

### 3.5 与知乎社区生态的契合度

域途把知乎「人与人围绕真实问题展开思辨」的社区机制，从「读别人的回答」推进到「在自己的处境里对照观点、领走下一步」。

| 社区机制 | 域途的对应设计 |
|---|---|
| 真实问答 | 256 条问答摘要与原文链接，每条可回溯，不转载全文 |
| 多元观点 | 不替用户下结论，只呈现不同处境下的经验与代价 |
| 赞同 / 收藏 | 升级为「有效标记」：一条复盘获得 3 个不同用户标记才升级为公共节点 |
| 内容沉淀 | 用户复盘、讨论、素材按意愿回流经验池，保留原文出处 |
| 合规边界 | 拿不到授权内容时显示缺口，不伪造内容；快照时间可见 |

## 4. 用户与场景

### 4.1 四类核心用户

| 阶段 | 典型画像 | 此时最痛的问题 | 域途提供的第一个抓手 |
|---|---|---|---|
| 在校探索期 `explore`（16–23） | 在校高年级 / 即将毕业 | 方向太多、信息太杂，不知道先试什么 | 七维定位 + 方向清单 + 一条低成本体验任务 |
| 初入职场期 `entry`（22–27） | 工作 1–5 年，第一份工作定调 | 对口岗位的真实日常与预期不符 | 二阶检索 + 作战图代价 + 可迁移能力盘点 |
| 转向抉择期 `pivot`（26–33） | 已有存量经验，考虑转行 | 存量经验能不能迁移、窗口还剩多久 | 归属摘要 + 过渡带 + 沙盘推演 |
| 稳态深耕期 `anchor`（32–45） | 家庭与现金流约束变硬 | 不能归零重来，只能做增量 | 资源约束下的沙盘 + 阶段性胜利归档 |

> 阶段由年龄、身份与七维共同判定，但**不作为标签展示**；界面只显示「当前阶段」与判定依据，用户可回第 1 步修改。

### 4.2 非目标用户

- 期待系统直接给出「你该去哪、该做什么」的人。
- 需要即时职位投递或薪酬谈判的人。
- 需要心理干预或危机支持的人（应转向专业机构）。

### 4.3 典型旅程

**首次 15 分钟**

```
第 1 步 填写信息（约 6 分钟）
  → 七维向量 + 阶段判定 + 填写质量
第 2 步 了解环境（约 3 分钟）
  → 定位城市 → 区域圈 → 人群 → 证据 → 原文
第 3 步 方向与推演（约 5 分钟）
  → 方向清单 → 选一条 → 二阶深挖 → 代价与清单 → 归属摘要
第 4 步 成长闭环（约 1 分钟）
  → 领取 1 条体验任务，离开
```

**一轮闭环（1–4 周）**

```
体验任务（doing） → 标记完成（done） → 停靠自省（三问）
  → 归档（keep / revise / rest / switch） → 处境漂移 ΔS
  → 回看落点：方向是否改变？
      ├─ 没变：继续本轮 / 开启下一轮
      └─ 变了：回第 1 步重填（历史记录保留）
```

### 4.4 Jobs to be Done

1. 当我站在十字路口时，帮我**看清自己站在哪**，而不是先给我一个标签。
2. 当别人说「这条路好」时，帮我看**这一步具体要付什么**。
3. 当我做了一段时间后，帮我**对比起点与现在**，判断是否还要继续。
4. 当我停下来时，允许我**暂停而不被判定为失败**。

## 5. 产品方案

### 5.1 信息架构

```
/#/                      四步主流程（业务首页）
  ├─ STEP 01 填写信息
  ├─ STEP 02 了解你所处的环境
  ├─ STEP 03 方向与推演
  │    ├─ 01 方向清单
  │    ├─ 02 二阶深挖（右侧抽屉 / 移动端底部 sheet）
  │    └─ 03 归属与摘要（含资源作战图）
  └─ STEP 04 成长闭环
       ├─ 01 闭环顺序（当前步骤 + 完整六步）
       ├─ 02 闭环全貌（螺旋年轮）
       ├─ 03 本轮工作区（体验工作台 / 停靠驿站）
       └─ 04 档案与同伴（档案墙 / 同伴经验域）
/#/sandbox               沙盘推演（独立页，共用数据层）
```

**两大板块**（Shell 顶部）：

- **我的处境**：第 1–3 步，只读投影，不产生 `ΔS`。
- **我的成长**：第 4 步，唯一产生处境漂移的地方。

### 5.2 STEP 01 填写信息

**目的**：把「我是谁」从主观描述变成可核对的结构化事实。

| 区块 | 内容 | 输出 |
|---|---|---|
| 基本事实 | 常住城市、年龄、城乡、身份（学 / 工）、所学或所从事方向 | 事实字段 |
| 结构化测量 | 经济、家庭、行业周期、探索行为、体验历史 | 可观察指标 + 透明公式 |
| 校准量表 | 用户可手动覆盖计算结果 | 明确提示「覆盖计算」 |
| 判定结果 | 七维向量、阶段、填写质量（完整度 + 一致性） | 进入下一步的依据 |

交互要点：

- 顶部「快速定位」可跳转到四个区块，滚动时预留吸顶高度。
- 「显影」反馈：配图初始 66% 不透明 + 低饱和，用户首次聚焦 / 点击 / 输入后变清晰；文案为「你每写下一项，这张图就清晰一点。」
- 至少填写一个方向才允许进入下一步；其余步骤以「继续」作为完成动作。
- 修改后可回跳，不丢数据；首次进入生成 `ownerKey` 并持久化在本机。

### 5.3 STEP 02 了解你所处的环境

**目的**：用「结论 → 定位 → 人群 → 证据 → 原文」五段式，让用户先看清外部约束。

| 模块 | 说明 | 数据分级 |
|---|---|---|
| 区域结论 | 城市能级、产业密度、生活成本档位 | APPROX |
| GIS 地图 | Leaflet + OpenStreetMap，46 城可点选，277 km 区域圈，地理 / 网络双模式 | APPROX + 离线矢量 |
| 区域构成 | 圈内城市、岗位密度分级、邻近关系 | APPROX |
| 近期讨论 | 与所选方向相关的知乎原文摘要 + 原文链接 | REAL（快照，不运行时检索） |
| 数据来源 | 页头快照时间 + 每条数据挂来源徽标 | 五级来源 |

口径纪律：

- 地图飞线只表示**岗位密度 / 资料归属 / 邻近关系**，不表示「同路人的真实下场」。
- 底图加载失败时保留离线矢量陆地并提示，不白屏。
- 检索不到时如实显示「没有检索到直接相关的原文」，不用通用内容伪装。

### 5.4 STEP 03 方向与推演

**目的**：把「有哪些路」拆成三件事——有什么、深挖什么、要付什么。

**方向清单**

- 4 个阶段合计 18 条方向；每条含名称、可行性、前置条件、资源消耗、张力。
- 可行性由显式 `traits`（`job` / `cash` / `time` / `reset`）判定，不用方向名正则。
- 候选短名单最多 4 条，供第 4 步之前并排对比。
- 「你的想法」为折叠块：默认摘要，展开后可编辑，填写后参与检索。

**二阶深挖**

- 点击「选它 · 二阶深挖」打开右侧抽屉（移动端底部 sheet）。
- 抽屉内复用 `SecondStageSearch`：更具体的问题、原文、链接、代价提示。
- 支持关闭按钮、背景点击、Esc。

**资源作战图**

- Leaflet GIS，按 55 / 105 / 155 km 三层推进圈排布方向节点。
- 每个方向带扇区、推进飞线；资源仓显示一次性资源存量。
- 方向到资源的补给线、方向之间的张力线可独立开关。
- 飞线动画只表示推进 / 补给方向，**不代表速度、成功率或优先级**。

**归属与摘要（SET 视图）**

- 按 SET 四段呈现：S 处境 → C 约束 → R 相近经验 → T 迁移。
- 归属结论、稳定度、过渡带、逐维方向贡献。
- 归属视图不渲染 Voronoi 单元，也不画七维雷达：二维投影不参与计算，容易被过度解读。
- 归档后的向量快照用于「起点 → 现在」对比。
- 「一页纸摘要」在浏览器本地生成 Markdown / JSON，可复制或下载。

### 5.5 STEP 04 成长闭环

**目的**：把计划变成可完成、可暂停、可归档的一轮，并把经验留给后来者。

```
领取任务 → 去体验 → 标记完成 → 停靠自省 → 归档漂移 → 回看落点
```

- **体验工作台**：任务来自方向生成、沙盘采纳、用户自定义；六体分类；状态 `doing / done / hold / drop`。
- **停靠驿站**：三问自省 + 下一步选择 `keep / revise / rest / switch`；归档时保存归档前向量快照，再把漂移写回个人档案。
- **档案墙**：记忆 / 曲线 / 档案三个视图；展示胜利档案的标题、选择、三问原文、向量快照、完成清单、归属域与相似度档位。
- **同伴经验域**：复盘提交进入校验池，3 个不同用户标记有效后升级为公共节点；支持树状讨论、公开素材链接、包含匹配搜索。
- **我的贡献**：已提交复盘、公共节点数、累计有效标记、平均校验进度；不排名。
- **我的数据**：查看本机标识、复制、下载完整 JSON 备份。

### 5.6 沙盘推演 `/#/sandbox`

## 6. 核心机制与数据口径

### 6.1 七维处境向量

| 维度 | 含义 | 采集方式 | 来源分级 |
|---|---|---|---|
| `age` | 年龄 | 用户填写 | 事实 |
| `place` | 经济压力 / 可支配缓冲 | 结构化测量（收入稳定性、储蓄、负债、支出） | SELF |
| `family` | 家庭责任 | 结构化测量（赡养、抚养、异地、支持度） | SELF |
| `cycle` | 行业周期 | 结构化测量（招聘景气、岗位收缩、技能折旧） | SELF + APPROX |
| `inertia` | 认知惯性 | 结构化测量（信息源多样性、探索频率、沉没成本感） | SELF |
| `history` | 体验历史 | 结构化测量（相关经历、试错次数、可迁移成果） | SELF |
| 城市 / 城乡 / 身份 / 方向 | 地域与身份 | 基本事实 | 事实 / APPROX |

> 当前是**七维**，不是早期文档中的四维雷达。四维表述已废弃。

### 6.2 相似度与稳定度

```
similarity = (0.75 × 方向带权余弦 + 0.25 × 强度接近度) × √min(1, |v| / 0.5)
```

- 方向仍主导；强度项解决「只比方向、不比强度」。
- 收缩项让信息不足的用户显示「尚未落定」，而不是一个看似确定的高百分比。
- 界面只显示「相近 / 过渡 / 较远」档位（`simBand`），不显示百分比。
- 稳定度：绝对差用于展示；相对差 `(S1 − S2) / S1` 用于判定，高 ≥ 0.15，中 ≥ 0.06；模长 < 0.35 直接判低。
- 过渡带阈值 `bandEps = 0.06`。
- **未校准声明**：权重、阈值、公式均为启发式缺省，未用外部样本校准；界面统一挂 HEURISTIC 徽标，不得表述为「科学测评」或「精准匹配」。

### 6.3 归属分区与公共节点

- 每个方向节点是一个种子；「在七维空间里离它最近的范围」即它的 Voronoi 区域，这是相似度分配模型。
- 当前实现只做最近邻归属（`ranked` / `nearestNode`），**不渲染 Voronoi 单元边界**；`d3-delaunay` 仅用于开篇装饰序列的板块几何，**不参与归属计算**。
- 复盘升级为公共节点是派生规则，不新增表：`marks >= 3` 且取标记数最高的 8 条。
- 自己的节点（`author_key === ownerKey`）不参与自己的归属计算。
- 公共节点参与他人归属，构成外层的「经验共建闭环」。

### 6.4 SET 模型映射

| 段 | 含义 | 代码映射 |
|---|---|---|
| **S** Situation | 七维处境 + 阶段 | `profile.s` + `currentStage` |
| **C** Constraint | 方向可行性 | `feasibility` + `traits` |
| **R** Reference | 相近经验 | `ranked` / `similarityOf` + `reviews` / `marks` |
| **T** Transition | 归档漂移 | `DRIFT` / `DROP_DRIFT` / `archive` / `applyInactivityDecay` |

第 3 步的「归属与摘要」按 SET 四段式呈现，作为进入闭环前的最后一次确认。

### 6.5 数据来源五级

| 分级 | 含义 | 示例 |
|---|---|---|
| REAL | 真实公开原文快照 | 知乎回答 / 文章 + 原文链接 |
| SELF | 用户自己填写 | 七维测量、三问自省 |
| CURATED | 人工配置的案例 / 资源规则 | 精编案例、方向前置条件 |
| APPROX | 近似属性 | 城市能级、岗位密度、经纬度 |
| HEURISTIC | 系统规则推导 | 相似度、稳定度、沙盘效果、现金 / 精力 |

逐图表依据审计（`src/data/evidence-audit.ts`）登记每张图表的名称、页面、来源类型、状态（`grounded / partial / unfounded`）、界面位置、来源说明、缺口、补法与是否可在第 1 步补数据。

当前「无外部依据」7 项：

1. 归属相似度 / 稳定度
2. 长期记忆接近度
3. 沙盘预设动作效果
4. 沙盘现金 / 精力推导
5. 沙盘维持现状
6. 沙盘落点
7. 新用户初始档案

### 6.6 两条不同的门槛

| 门槛 | 作用对象 | 规则 | 执行时机 |
|---|---|---|---|
| 内容配置门槛 | 参考草稿 / 精编案例 | 同一路线至少 2 个独立来源交叉印证，孤证不生成草稿 | 内容运营阶段 |
| 公共节点门槛 | 用户复盘 | 至少 3 个不同用户标记有效 | 运行时派生 |

### 6.7 两条硬边界

1. **没有「同路人去向城市」字段。** 现有表只记录作者处境城市与下一步选择，地图飞线不得声称是「同路人的真实下场」。要落地必须先新增去向字段并取得明确授权。
2. **没有运行时大模型 RAG 直答。** 当前是「真实语料检索 + 固定规则」，不是生成式推演；不得用通用内容伪装成按方向检索。

### 6.8 漂移与衰减

| 事件 | 效果 | 持久化 |
|---|---|---|
| 归档 `keep / revise / rest / switch` | 按 `DRIFT` 表应用 `ΔS`，写回个人档案 | 平台档案表 + 本机快照 |
| 首次放弃任务 | 体验历史 +2、认知惯性 −1 | 平台任务状态 + 本机去重记录 |
| 30 天无新归档 | 体验历史与认知惯性小幅衰减 | 本机计算，界面明示 |

> 漂移是**规则**，不是预测。界面不展示「按此发展你会怎样」。

**禁令**：组件禁止直接 `fetch`，禁止消费后端列名。新接口按「建表 → 建 SQL API → 登记 `.project.md` → `yutuApi` → Context → 组件」顺序挂载。

### 7.4 身份与本机隔离

- 无独立账号体系；前端生成 `ownerKey` 并持久化在 `localStorage: yutu.ownerKey`。

- 换设备不自动合并个人数据；公共经验池不依赖账号。
- 「我的数据」可导出完整 JSON，便于迁移或删除。

### 7.5 降级与容错

| 场景 | 行为 |
|---|---|
| 无平台页面代理（本地 dev） | 自动切 `localStorage` 快照，顶部显示「本地存储模式」 |
| 初始化多个读接口 | `Promise.allSettled`，部分失败不整体降级 |
| 写接口失败 | 退回本机，不丢正在填写的内容 |
| 地图瓦片失败 | 保留离线矢量陆地 + 提示，不白屏 |
| 渲染异常 | 路由级 `ErrorBoundary`，提供恢复入口 |
| 沙盘 / 二阶检索 | 路由级 / 组件级懒加载，不阻塞首屏 |
| 不支持的浏览器特性 | View Transition / IntersectionObserver 缺失时降级为直接切换 |

### 7.6 性能与可访问性

| 项 | 现状 |
|---|---|
| 首屏主包 | 约 354 KB / gzip 139 KB（2026-11-25 实测） |

| 图片 | WebP 优先 + JPG 兜底；静态颗粒层在动效关时隐藏 |

| 移动端 | ≤820px 取消吸顶；≤760px 电路图横向滚动；≤980px 玻璃轨转横线 |
| 对比度 | 暗色玻璃体系统一使用 `--y-ink` / `--y-ink2` / `--y-muted`；来源徽标统一为暗色 |

### 7.7 工程门禁

- 每次改动后必须通过 `pnpm type-check` / `pnpm lint` / `pnpm build`。

| 分享 / 共建 | 复盘、讨论、素材、搜索都可写 | 无通知、无举报 / 折叠、无内容运营后台 |

### 8.3 明确缺口（不假装有）

1. **账号体系与跨设备同步**：当前只有本机 `ownerKey`。
2. **同路人去向城市**：无字段、无授权流程，地图飞线不得声称是真实去向。
3. **运行时 RAG 直答**：未接入；当前为检索 + 规则。
4. **模型校准**：相似度 / 稳定度 / 漂移权重未用外部样本校准。
5. **沙盘效果依据**：预设动作七维效果是规则假设，不是样本均值。
6. **内容审核后台**：公共池只有「3 人标记」门槛，缺运营工具。
7. **无障碍完整验收**：已有键盘与减动效支持，但未做屏幕阅读器全流程回归。

### 8.4 质量记录

- V11.9–V11.19 每次改动均记录 `type-check` / `lint` / `build` 通过。
- 旧版白屏问题已用四层兜底修复：ErrorBoundary / 地图降级 / 首屏兜底 / noscript。
- 2026-11-25 构建实测：首屏 354 KB、gzip 139 KB。

## 12. 风险与对策

| 风险 | 表现 | 对策 |

| 伦理风险：被读成「人生规划器」 | 用户期待系统给答案 | 全站禁令措辞；空态与边界提示；演示脚本先讲「不做什么」 |

### 13.1 原创与参赛声明

### 13.2 素材构成

视觉素材由三部分组成：**团队原创 / AI 生成（部分，已如实披露）/ Unsplash 免费图库（Unsplash License）**；不含第三方受版权保护的作品，未使用带水印或来源不明的图片。完整核查表见 `docs/ASSET-LICENSES.md` 与 `docs/IMAGE-SOURCES.md`。

### 13.3 知乎内容使用边界

- 只保存问答摘要与原文链接，不转载全文，不复刻原文。
