# 提交包

> 用途：知乎黑客松 S3 提交时，从这个目录直接取文件。
> 更新时间：2026-11-26

## 目录内容

| 文件 | 用途 | 必交 |
|---|---|---|
| `提交信息.md` | 表单文案：作品名 / 赛道 / 简介 / 亮点 / 契合度，可直接粘贴 | 参考 |
| `域途-产品说明计划书.docx` | 产品说明计划书（含知乎生态契合度专章） | ✅ 必交 |
| `域途-产品说明计划书.pdf` | PDF 版（有则优先提交 PDF + DOCX） | 建议 |
| `演示视频-说明.md` | 视频链接与分镜脚本索引 | 选交 |

## 当前缺口

| 材料 | 状态 | 谁来做 |
|---|---|---|
| 平台 `prod` 链接 | ⬜ 待发布 | 你在平台点「发布」 |
| 演示视频 | ⬜ 待录制 | 按 `docs/VIDEO-SCRIPT.md` 录 |
| PDF 版计划书 | ⬜ 待导出 | 见下方命令 |
| 团队信息 | ⬜ 待填写 | 你 |

## 生成 / 更新

```bash
# 1) 重新导出计划书 DOCX（改完 md 后）
python3 scripts/build_plan_docx.py \
  --src "docs/域途-产品说明计划书.md" \
  --out "submit/域途-产品说明计划书.docx" \
  --title "域途 · 产品说明计划书（V12.4）" \
  --footer "域途 · 产品说明计划书" \
  --simple-headings

# 2) 导出 PDF（任选其一）
#   a. LibreOffice：soffice --headless --convert-to pdf submit/域途-产品说明计划书.docx --outdir submit/
#   b. 浏览器打开 DOCX 预览 → 打印 → 另存为 PDF（保真度最高）

# 3) 打包（可选，方便上传）
cd submit && zip -r ../域途-提交包-$(date +%m%d).zip . -x "*.md"
```

## 提交顺序

1. 先把 `提交信息.md` 里所有 `【 】` 填掉
2. 打开平台 prod 链接，用无痕窗口走一遍四步
3. 按知乎表单顺序填：作品名 → 赛道 → 链接 → 计划书 → 仓库 → 视频 → 团队
4. 提交后**截图保存成功页**（提交窗口关闭后无法再改）
