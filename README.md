# 域途 · V2 工程版（2026-11-19）

> 本版把交接包里的多文件 HTML 原型升级为可构建、可持久化的 React 应用。
> **原始交接说明保留在下方**（从「域途项目 · 交接说明」开始），其中的模型推导、
> 数据来源与已知缺口仍然有效。

## 这一轮做了什么

- **工程化**：Vite 5 + React 18 + TypeScript + HashRouter；`/#/` 直接进入五步主流程。
- **五步完整流程**：填写信息 / 地理与人群 / 方向与推演（清单 + 作战图）/ 沃罗诺伊 / 成长闭环。
  第二步与第四步使用 Leaflet GIS 地图，沃罗诺伊使用 SVG，视觉与交互保持统一。
- **真实持久化**：在项目空间建了 5 张数据表、12 个 SQL 操作 API（详见 `.project.md`）。
  个人档案、体验任务、胜利档案、同伴复盘、有效标记都走 `POST /api/page/w/{token}`。
- **外层闭环落地**：复盘进入校验池，满 3 个有效标记后升级为公共节点；
  公共节点参与他人的归属计算，但**自己贡献的节点不会参与自己的归属**。
- **补齐脑图里两项未实现设计**：
  - 「经验卡」：比整条复盘更轻的提交颗粒度，直接进同一个校验池。
  - 「随时间自身滑落」：30 天无新归档时，体验历史与认知惯性小幅衰减，并在界面明示。
- **知乎内容快照（本轮新增）**：安装官方 `zhihu-cli` Skill 后，用真实检索结果生成
  `src/data/zhihu-snapshot.json`（256 条，覆盖 14 个专业大类、46 个城市、4 个阶段）。
  第 2 步的「近期讨论」与第 3 步的「近期社区讨论」直接展示这些回答/文章摘要与原文链接，
  并在页头标注快照时间。快照只读公开内容，不包含个人隐私数据。
- **专业大类从 6 个扩展到 14 个**：新增法学、新闻传播、物流/供应链、旅游/酒店、
  外语/翻译、设计/艺术、心理/社工、农学/畜牧/园林；未命中时仍回落到阶段通用结果。
- **城市库扩展到 46 个，覆盖全部 34 个省级行政区**（含直辖市、自治区、港澳台），
  第一步的常住城市选择按省级行政区归组；每个城市补齐经纬度，GIS 地图与区域统计都可正常定位。
- **降级策略**：本地 `vite dev` 没有平台页面代理时自动使用 `localStorage`
  （键 `yutu.state.v2`），顶部状态条会显示「本地存储模式」；平台内打开时自动切回数据表。
- **数据接入状态（2026-11-20）**：页头 chip 可展开，逐项显示个人档案 / 体验任务 /
  胜利档案 / 同伴复盘 / 有效标记 5 个读接口的探测结果与上次同步时间；
  「重新同步」会重新拉取这 5 项，失败项继续沿用本机缓存；写接口失败时自动退回本地，
  不会因为一次网络错误丢掉正在填写的内容。
- **贡献者影响力与个人数据（2026-11-20）**：第五步「同伴经验域」新增
  「我的贡献」概览（已提交复盘 / 公共节点 / 累计有效标记 / 平均校验进度），
  仍不设排行榜；新增「我的数据」卡片，可查看本机标识、复制标识、下载完整
  JSON 备份。备份完全在浏览器本地生成，包含档案、任务、胜利、自己的复盘与标记记录。
- **重新填写二次确认**：第五步底部的「重新填写」现在会先说明影响范围——
  重置本次浏览与本机快照（本机标识保留），但不会删除平台数据表中的记录；确认后才执行，避免误触。
- **V3 体验升级**：
  - 全局「进度概览」条：阶段、城市、归属域、胜利数、候选数与七维指纹，跨页面可见；

## 预览白屏兜底（已修复）

Leaflet 在预览沙箱中曾出现 `_initContainer` 的 `appendChild` 未定义错误，导致整页白屏。已做四层兜底：

- 地图初始化前校验容器是否为真实 DOM 节点，避免把 ref 对象/空节点传给 Leaflet；
- `L.map` 与图层渲染包裹 `try/catch`，失败时只显示地图区域占位，不影响页面其他内容；
- 应用根增加 `ErrorBoundary`，单个视图异常不再清空整个应用；
- 移除 `StrictMode` 的双挂载，避免开发态地图容器被初始化两次。

如果预览仍出现白屏，先看控制台是否有 Leaflet 初始化错误，再强制刷新页面。

> 地理模式/网络模式切换时，地图会先显示离线矢量陆地，再加载 OSM 瓦片；即使瓦片被网络策略拦截，也不会出现空白图。

## 依赖安装失败（已修复）

平台安装器在检测到 pnpm store 变化时会删除 `node_modules/.modules.yaml` 并尝试重建
modules 目录；无 TTY 环境下 pnpm 10 会直接中止并返回：

```
ERR_PNPM_ABORTED_REMOVE_MODULES_DIR_NO_TTY
Dependency installation failed: Exit code 1, Signal null
```

已在 `pnpm-workspace.yaml` 与 `.npmrc` 中固定 `confirmModulesPurge: false`，
让 pnpm 自动重建而不是等待交互确认；同时用 `pnpm install --prefer-offline`
重新生成了一致状态的 `node_modules`。若以后仍遇到，先执行一次
`pnpm install --prefer-offline` 即可。

## 知乎 CLI 与内容快照

- Skill 安装目录：`.claude/skills/zhihu`（同时同步到 `.agents/.codex/.opencode/skills`）。
- CLI：由 Skill 的 `scripts/setup.sh` 安装到 `~/.local/share/zhihu-cli/current/zhihu-cli`。
- 本沙箱没有系统密钥链，凭证通过 `ZHIHU_ACCESS_SECRET` 注入；仓库内**不保存**任何 Secret。
- 刷新快照：

```bash
export ZHIHU_ACCESS_SECRET=...
python3 scripts/refresh-zhihu-snapshot.py
```

脚本会执行 26 个检索查询并覆盖 `src/data/zhihu-snapshot.json`，随后重新构建即可生效。
快照是**一次性检索结果**，不会在浏览器打开时实时更新；实时调用需要后端持有凭证，
不能把 Access Secret 放进前端。

## 3. 两个原型的关系

## 3.1 当前主交付物：`yutu-flow-prototype.html`

五步**强制顺序**流程，后续步骤在前一步完成前处于 `disabled`：

| 步骤 | 内容 | 关键实现 |
|---|---|---|
| ① 填写信息 | 城市、年龄、身份、专业方向、五维处境量表 | 地理维度由城市属性导出，不自评 |
| ② 了解你所处的环境 | 地理定位 + 区域构成 + 去向分布 + 地域检索 | V4 已改为 Leaflet GIS 地图 |
| ③ 方向与案例 | 该阶段全部方向 + 可行性三档 + 真实案例 | 按填写的专业匹配检索结果 |
| ④ 资源与窗口 | 一次性资源存量 + 态势图 + 代价明细 + 方向张力 | 约束全部来自知乎检索，附原文引用 |
| ⑤ 你的沃罗诺伊 | 七维向量相似度归属 + 模型边界提示 | 综合相似度（方向 + 强度），含边界与中性区提示 |
| ⑥ 成长闭环 | 体验工作台 / 停靠驿站 / 胜利档案墙 / 同伴经验域 | 双层闭环，见 3.4 |

### 第 ④ 步：资源与窗口态势图

用户原始需求是"战役态势图"，隐喻已**降级为推演**——不设主攻目标、不给成功率、不把任何人设为敌军，
因为这三者都与 Word 方案 7.1「不做终点任务」、12.1「不做结果预测」直接冲突。

核心不是"打哪个方向"，而是**"你手上还有哪些一次性资源、哪些窗口正在关闭、走某条会消耗什么"**。

三项消耗型资源（全部有检索依据）：

| 资源 | 规则 | 失效条件 |
|---|---|---|
| 应届生身份 | 择业期 2 年；接 offer 即自动放弃考公考编与其他校招通道 | 已落实工作且超择业期 |
| 统招专升本报考资格 | 在校可报考，毕业即失效，之后只能走非全日制 | 毕业 |
| 低成本试错窗口 | 由经济压力、家庭负担、年龄合成 | 随处境变化 |

四组方向张力（互斥 / 条件相关 / 共用资源）同样来自检索，每条附原文引用与链接。
DOM 元素 id 为 `y-p5`，但在步骤条上显示为第 4 步——`PANELS` 数组顺序是
`[y-s1, y-s2, y-s3, y-s5, y-s4]`，改导航时注意这一点。

### 3.2 关于 `yutu-flow-data.js`

**注意**：该文件的内容**已经内联**进 `yutu-flow-prototype.html` 的第一个 `<script>` 块中。
原因是发布沙箱禁止外部脚本（`no external scripts`）。

- 要改数据：直接改 HTML 内联的那段，或改 `.js` 后用脚本重新内联
- 不要在 HTML 里写 `<script src="yutu-flow-data.js">`，会被发布器拒绝

### 3.3 旧版 `yutu-career-prototype.html`

六个模块做成平级页签（环境地图 / 体验工作台 / 停靠驿站 / 胜利档案墙 / 同伴经验域 / 陪伴角色）。
它是**双层闭环逻辑的原始来源**，第六步的实现从它迁移而来。

**不要删除它**。它仍是闭环细节（时间戳、校验池门槛、载入态复位三个修复）的参照版本。

### 3.4 第 ⑥ 步：成长闭环（本版新增）

前四步是一次性的认知链路，第五步把系统变成可循环的。四个子模块做成**子页签**（非平级页签），
DOM id 为 `y-t1~y-t4`（页签）与 `y-m1~y-m4`（面板）：

| 子模块 | 作用 |
|---|---|
| 体验工作台 | 从当前域载入参考任务（六体分类），可增删改状态；自定义任务与系统草稿权重相同 |
| 停靠驿站 | 三问自省 + 下一步选择（维持/修改/休整/更换），归档为阶段性胜利并触发向量漂移 |
| 胜利档案墙 | 时间轴 + 向量快照 + 两点对比小地图（与第五步同一套投影与量纲） |
| 同伴经验域 | 提交复盘到校验池，满 3 个有效标记后升级为公共节点 |

**内层闭环**：载入任务 → 标记完成 → 驿站停靠 → 归档为胜利 → 七维向量小幅漂移 → 回第 2/5 步重新定位。
漂移量由"下一步选择"决定（`DRIFT` 表），归档时同时更新滑块、地球、方向、态势图与沃罗诺伊（`refreshAll()`）。

**外层闭环**：复盘 → 校验池 → 3 个有效标记 → 升级为 `NODES` 中的公共节点，进入他人的知识网络。

两条关键设计约束：

1. **空复盘不进校验池**。至少一问填 ≥8 字才允许提交，否则按钮 disabled 并显示"内容不足，不可提交"。
2. **自己贡献的公共节点不参与自己的归属计算**。升级后的节点带 `own:true` 标记，
   `ranked()` 与 `nearestNode()` 都会跳过它——否则会与自己的快照 100% 重合，变成自己匹配自己。
   该节点对他人依然可见。

主脚本通过 `window.__YUTU_LOOP__` 向闭环模块注入共享引用：
`ST / DIMS / NODES / current() / clampDim() / proj() / nearestNode() / refreshAll()`，
闭环模块回传 `renderLoop()` 与 `resetLoop()`。改任一侧都要对齐这个契约。

「重新填写」会同时复位向量（`INIT` 快照）、清空任务与档案、并把 `NODES` 截回 `BASE_NODES` 长度，
移除本次会话升级的公共节点。

**注意 `PANELS` 顺序**：`[y-s1, y-s2, y-s3, y-s5, y-s4, y-s6]`——第 4 步的 DOM id 是 `y-p5`，
第 4 步是 `y-p4`，第 5 步是 `y-p5`。改导航时按数组下标而不是 id 数字。

## 4. 开发与验证方式

### 4.1 预览

发布沙箱是离线隔离 iframe，不能直接开 `file://`。本地验证流程：

```bash
cd <workspace>
python <skill-dir>/scripts/export.py yutu-flow-prototype.html "$BOX_AGENT_SCRATCH_DIR/qa.html" --title "QA" --language zh
cd "$BOX_AGENT_SCRATCH_DIR" && "$BOX_AGENT_PYTHON" -u -m http.server 0 --bind 127.0.0.1 --directory .
# 从输出读端口，再用浏览器工具访问 http://127.0.0.1:<port>/qa.html
```

### 4.2 发布

```bash
python <skill-dir>/scripts/publish.py yutu-flow-prototype.html --title "标题"
```

发布器只校验结构与语法，**不执行**脚本。所以发布成功不等于交互正常，必须另行浏览器验证。

### 4.3 片段约束（踩过的坑）

- 不能有 `doctype` / `html` / `head` / `body` 包装
- 不能用 `<form>` + `type="submit"`，沙箱拒绝表单提交；要用 `type="button"` + click handler
- 不能用 `localStorage` / `sessionStorage`
- canvas 固定宽高会在窄屏溢出，必须配 `width:100%;height:auto`
- 用 `write_file` 分块写大文件时，**不要**在每块结尾写 `</script>`，否则会在文件中间留下孤立闭合标签

## 5. 知乎检索怎么调

CLI 路径与鉴权：

```bash
unset ZHIHU_ACCESS_SECRET   # 重要：环境变量会覆盖密钥库，见下
CLI="C:/Users/colorful/.box-agent-kanshan/cli/zhihu/current/zhihu-cli.exe"
"$CLI" search zhihu  --query "关键词" --count 6
"$CLI" search global --query "关键词" --count 6
"$CLI" hot --limit 20
```

**已知环境问题**：进程环境里存在 `ZHIHU_ACCESS_SECRET`（由桌面客户端注入，非用户级/系统级环境变量），
其值与密钥库中的不同但同样有效。CLI 优先级是「环境变量 > 密钥库」，
所以要用密钥库里那把密钥时**必须先 `unset`**。详见 `docs/DATA-SOURCES.md`。

另注：bash 中路径不要用反斜杠形式嵌在双引号里做变量赋值，会触发 `bad escape \U`；用正斜杠。

## 7. 必须知道的已知缺口

**不要把下面这些当作已完成。**

### 7.1 模型层（2026-11-21 已做模型层修复，权重仍待校准）

- **方向 + 强度**：归属改用综合相似度（方向余弦 0.75 + 强度接近度 0.25 + 低信息收缩）。
  同向但严峻程度差一倍的两人不再得到恒为 1.000 的相似度，实测约为 0.87。
  剩余问题：权重是启发式缺省，**尚未用外部样本校准**。
- **中性区归属不稳定**：1 分变化仍可能让边界附近的两个域互换排名，这一点无法从根上消除。
  系统现在会把低模长整体收缩、稳定度判“低”，并提示按过渡带理解，而不是给出确定标签。

参数集中在 `src/lib/model.ts` 的 `MODEL_PARAMS`，便于后续校准与回归对照。

### 7.2 数据层

- **同阶段去向**：第 2 步读的是平台胜利档案的匿名聚合（同阶段满 5 条才显示占比），不再是示意数据。
- **城市属性是近似值**：22 个城市的 `jobs`（岗位密度）/`cost`（生活成本）按常识填写，非权威统计。
  > V3 已扩展到 46 个城市、覆盖全部 34 个省级行政区；新增城市仍为近似示意值。
- **权重 0.7/0.3 无依据**：地理维度公式 `0.7×jobs + 0.3×cost` 中这组系数是拍的，直接决定成都(76)与杭州(87)的差距。
- **检索结果是快照**：第 2、3 步的知乎内容是一次性抓取后内置的，**不会随打开时间更新**。
  正式版本需在运行时调用 zhihu-cli。
- **专业大类只有 6 个**：土木/护理/IT/学前教育/会计/机电。填「考古学」「哲学」等会回落到通用结果。
  > V2 已扩展到 14 个（新增法学、新闻传播、物流/供应链、旅游/酒店、外语/翻译、设计/艺术、
  > 心理/社工、农学/畜牧/园林）；仍未命中的方向会回落到阶段通用案例 + 阶段级近期讨论。
- **方向张力只覆盖学生阶段**：4 组张力的两端都是 explore 阶段的方向，因此已工作者进入第 4 步时
  「方向之间的张力」显示空态。其他阶段的互斥关系尚未检索。
- **态势图有 2 个标签仍被截断**（「考公 / 事业单位 /…」「专升本 / 考研提升学…」），
  已配 `<title>` 悬停可见完整名称。

### 7.3 功能层

- 双层闭环已补齐（见 3.4），但**同伴经验域的 4 条同处境复盘是虚构示例**，界面已标注
- 「有效标记」已接入平台数据表（`marks_add` / `marks_list`，按 `(review_id, marker_key)` 记录）；
  3 个标记的门槛仍是产品演示值，不是统计显著标准；离线模式保留本地模拟按钮
- 公共节点的困扰清单是占位文案（"困扰清单由贡献者填写"），没有让贡献者填这一项的入口
- 年龄漂移规则简化为"每 3 次胜利 +1 岁"，不是真实时间推进
- GIS 底图依赖 OpenStreetMap 瓦片；离线或瓦片失败时回落到 Natural Earth 1:110m 矢量陆地。城市属性仍为近似示意值。
- 空隙照片来自 Unsplash，遵循 Unsplash License，已随项目打包；来源见 `docs/IMAGE-SOURCES.md`。
- 结构化处境测量是透明自评工具，不是经过信效度检验的心理量表；公式权重是工程假设，尚未做大样本校准。
- 数据会写入平台数据表（本地无代理时降级到 `localStorage`）；「重新填写」只重置本机视图与快照，
  不删除平台记录，重新打开页面时仍会同步回来
